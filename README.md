# Mellon · фундамент, управление и профиль

Flutter для Android и Web + Supabase PostgreSQL/Auth/RLS/Realtime. Светлая минималистичная тема, мягкие голубые акценты; dark/system предусмотрены сразу.

**Статус:** управление чатами проверено пользователем на Mac: analyze без замечаний, 63 теста прошли; создание комнаты и отправка работают. Исправлено направление сортировки меню прихода: меньшее значение порядка — выше. Flutter-проверки этой правки выполняются на Mac.

**Для установленной версии управления чатами:** [исправление порядка](docs/CHAT_ORDER_FIX.md), без миграций. Для версии с новым меню прихода сначала нужно [управление чатами и каналами](docs/CHAT_ADMIN_UPDATE.md).

## Быстрый локальный запуск

Требуются Flutter 3.47.2 в PATH, Python 3, Supabase CLI и Docker. Dart поставляется с Flutter. Android Studio/SDK нужны для Android; для проверки Web достаточно Chrome.

```bash
bash scripts/bootstrap.sh
supabase start
supabase db reset
cp config/development.example.json config/development.json
```

`db reset` стирает **локальную** базу проекта и применяет миграции/демоданные. Не добавляйте `--linked` и не выполняйте reset на рабочем проекте.

В `config/development.json` укажите URL, **publishable key** из `supabase status` и адрес возврата `http://localhost:8080/`. Допускается legacy `anon` JWT для совместимости с локальным CLI. Secret/service-role ключи не подходят и отклоняются конфигурацией приложения. `--dart-define` не скрывает значения от пользователя.

```bash
flutter run -d chrome --web-port=8080 --dart-define-from-file=config/development.json
```

Первый запуск `bootstrap.sh` создаёт Android runner штатной командой `flutter create` во временной папке, добавляет Internet permission/Auth callback, минимальный API 24 и отключает резервное копирование данных приложения. Готового `android/` в архиве нет: его нужно сгенерировать этим скриптом, затем сохранить в Git вместе с `pubspec.lock`. Файлы `lib/` и `web/` скрипт не заменяет.

Для Android emulator URL локального Supabase — `http://10.0.2.2:54321`, адрес Auth callback — `org.moyprihod.app://login-callback/`. Для физического Android используйте HTTPS-проект Supabase. Локальный HTTP может потребовать отдельной debug network-security-конфигурации Android; не разрешайте cleartext в release.

```bash
flutter run -d <android-device-id> --dart-define-from-file=config/android-development.json
```

## Что уже в коде

- Feature-модули, контракты репозиториев, внедрение зависимостей и состояние Riverpod.
- Навигация go_router с независимыми ветками, прямыми ссылками и проверкой сессии для приватных разделов.
- Адаптивная оболочка, централизованные темы/типографика/отступы, сохраняемый выбор оформления.
- Вход/регистрация по email и паролю, запрос членства, каталог приходов, лента с курсором.
- Базовые списки событий/помощи, чаты с последними 50 сообщениями и отправкой через RPC, входящие уведомления.
- 22 таблицы, 9 миграций, RLS, расширяемые роли, серверные RPC, аудит и таблицы будущей push-доставки.
- Формы управления приходами и публикациями, черновики/архив, одобрение и отклонение заявок, серверная проверка разрешений.
- Управление чатами и каналами: отдельный репозиторий, формы, архив/восстановление, ревизии, серверное право chats.manage.
- Личный профиль: отображаемое имя, приватные имя/фамилия/дата рождения, настройка видимости, атомарное сохранение и защита от конфликта версий.
- Web manifest, иконки, apple-touch-icon, standalone-режим, страница отсутствия соединения.

Карта — порт `MapGateway` и экран-заготовка. Телефонная авторизация, восстановление пароля, push worker, вложения, полная история чатов, пагинация всех каталогов, геопозиция и расширенное модераторское управление — следующие этапы. Таблицы очереди и подписок сами ничего не отправляют.

## Проверки

```bash
cd supabase/tests
npm install
npm test
cd ../..
bash scripts/check.sh
```

Выполнены 124 проверки SQL/PostgreSQL через PGlite (64 базовые, 19 административных, 20 профиля и 21 управления чатами), разбор Dart-синтаксиса и проверки структуры. PGlite проверяет реальные SQL-политики, но использует заглушку `auth.uid()` вместо полного Supabase. Результат не заменяет интеграционную проверку Supabase Auth, PostgREST и Realtime.

## Следующий шаг

Установить исправление по `docs/CHAT_ORDER_FIX.md`, выполнить Flutter analyze/test и запустить приложение. Проверить, что в «Mellon → Чаты» запись с порядком 30 выше записи с порядком 40, а после изменения на 20 её положение меняется. Новая миграция не требуется.

# Mellon — интерактивная карта

## Установка

Сохраните `update_mellon_map.py` в Downloads. В терминале:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_map.py
```

Установщик проверяет исходные файлы до записи и создаёт резервную копию рядом с проектом. Неизвестные локальные изменения останавливают установку. Настройки подключения остаются прежними.

Для меток событий один раз выполните **в существующем проекте Supabase → SQL Editor → New query** весь файл `supabase/updates/map_events.sql`. Нажмите Run. Повторное выполнение этого файла допустимо. Он добавляет поля к событиям и обновляет две функции сохранения, сохраняя проверки прав и конфликтов редактирования. Затем:

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Для опубликованного сайта выполните прежнюю сборку с AUTH_REDIRECT_URL вашего сайта и обновите папку build/web на Netlify. Локальная установка сама по себе опубликованную версию не меняет.

## Карта и карточка

- Карта перемещается пальцем или мышью, масштабируется жестом, колесом и кнопками +/−.
- Метка храма Александра Невского: Калининград, ул. Александра Невского, 8; координаты 54.723306, 20.526467.
- Карточка открывается поверх карты примерно на 40% высоты экрана. Её открытие, раскрытие графика и закрытие свайпом вниз не меняют центр и масштаб карты. На маленьком экране содержимое прокручивается, действия остаются внизу.
- Фото показано с сохранением пропорций и обрезкой под форму метки/карточки. График по заданию: «Ежедневно с 8 до 19».
- «Узнать расстояние» или «Моё местоположение» вызывает штатный запрос разрешения. Без разрешения карта, маршрут и ссылка работают. Фоновое слежение не включено; координаты пользователя не отправляются в базу Mellon.
- Расстояние с иконкой пешехода подписано «по прямой». Это географическое расстояние, не длина пешеходного маршрута. «Проложить маршрут» открывает пешеходный маршрут в Яндекс Картах; если местоположение не получено, начальную точку можно указать там.
- «Поделиться» вызывает системную отправку ссылки; в браузерах без этой возможности ссылка копируется. Сам Mellon ничего не отправляет другим людям без действия пользователя.

## События

Переключатель **«Показать на карте»** добавлен в редактор событий прихода/области управления и в окно информации клуба (события и расписание). Включите его, выберите место на интерактивной карте и сохраните событие. Выбор точки обязателен; само включение не меняет видимость события.

Вверху карты появляются опубликованные события с выбранной точкой и датой начала на сегодняшний день **по времени Калининграда**. Черновики, отменённые, архивные и события других дней не показываются. Если событий несколько, плашки листаются горизонтально. Нажатие плавно переводит карту к точке; последующее касание метки открывает карточку события.

Список обновляется после сохранения, при возврате приложения и каждые 30 секунд, пока карта видима. Смена аккаунта сбрасывает полученные данные. Если событие перестало быть доступно, его открытая карточка закрывается. Чужие закрытые события отфильтровываются серверными правилами RLS, а не только интерфейсом. Пользователь без прав не может сохранить метку через RPC или прямой запрос к таблице.

## Геолокация и платформы

Веб-геолокация требует HTTPS либо localhost. Для установленной на домашний экран веб-версии действует разрешение браузера/сайта. Постоянный запрет меняется в настройках браузера или устройства.

Исходный архив содержит веб-платформу. Если в вашем проекте уже есть Android/iOS/macOS, установщик добавит только недостающие разрешения: INTERNET/ACCESS_COARSE_LOCATION/ACCESS_FINE_LOCATION для Android, NSLocationWhenInUseUsageDescription для iOS, NSLocationUsageDescription и entitlement геолокации для macOS. Нативную сборку и системные окна разрешений необходимо проверить на соответствующем устройстве.

- [Geolocator](https://pub.dev/packages/geolocator) — запрос разрешения и разовое местоположение.
- [Условия стандартных тайлов OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/). Атрибуция видна на карте. Работает штатное HTTP-кэширование; скачивание городов и предварительная загрузка областей не добавлены.

При необходимости провайдер тайлов меняется параметрами сборки `MAP_TILE_URL`, `MAP_ATTRIBUTION`, `MAP_ATTRIBUTION_URL`. Для большой нагрузки следует использовать подходящий тариф поставщика карт или собственные тайлы. Не ограничивайте Referer для стандартного сервера OSM.

## Проверки

`flutter test` включает проверки жестов, сохранения положения карты при карточке, анимации перехода к событию, отказа в геолокации, ссылки/маршрута, маленьких экранов и увеличенного текста, выбора точки и передачи метки в обе формы сохранения.

Проверки базы:

```bash
cd supabase/tests
npm ci
node map_events_integration.mjs
```

Используется отдельная тестовая база PGlite. Проверяются повторная миграция, видимость для гостя/участника/чужого клуба, полномочия админа, некорректные координаты, конфликты редактирования, совместимость старого клиента и границы дня Калининграда.

После установки проверьте на телефоне реальную загрузку карты, запрос геолокации, открытие внешнего маршрута и системную отправку ссылки. Автоматические проверки жестов используют тестовые тайлы, а не скачивают карту с публичного сервера.

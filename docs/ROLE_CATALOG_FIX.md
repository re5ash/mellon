# Исправление карточки управления ролями

В присланном журнале завершились успешно 147 тестов, три теста остановились из-за одного дефекта оформления. Переключатель подтверждения гостевого доступа находился внутри окрашенной карточки без собственного слоя Material, поэтому Flutter сообщал, что фон и эффекты нажатия ListTile могут быть перекрыты.

Внутрь карточки добавлен прозрачный Material. Белый фон, голубые акценты, тени, размеры и расположение элементов сохранены. В тестовых данных также указан явный тип пустого списка ролей, чтобы устранить предупреждение анализатора.

Существующие тесты сохранены. Проверки ошибок Flutter не отключались; логика прав, радиокнопок и сохранения не менялась.

## Установка

Скачайте `fix_mellon_role_catalog.py` в «Загрузки» и выполните в терминале:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_role_catalog.py
flutter analyze
flutter test
```

Установщик проверяет исходные версии файлов до записи и создаёт резервную копию рядом с проектом. При повторном запуске повторно изменять файлы не будет. Конфигурация Supabase и исправления входа сохраняются.

Это исправление не требует нового SQL. Если `mellon_role_catalog.sql` из предыдущего обновления уже выполнен, повторять его не нужно. Если ещё не выполнен, он по-прежнему требуется для загрузки каталога ролей.

После успешных проверок запустите приложение:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

## Проверка пакета

Проверены синтаксис изменённых Dart-файлов, установка поверх предыдущей версии, резервная копия, повторный запуск, сохранность конфигурации, отказ при конфликте и откат при ошибке записи. Файлы базы данных и авторизации не менялись.

Flutter SDK в среде подготовки отсутствует. Команды `flutter analyze` и `flutter test` необходимо выполнить на вашем Mac; синтаксический разбор не заменяет их.

# Mellon — молодёжный клуб и регистрация

## Установка в текущий проект

1. Остановите запущенный Flutter клавишей `q` в его терминале.
2. Скачайте `update_moy_prihod_club_registration.py` и `mellon_club_applications.sql`.
3. В Supabase откройте **SQL Editor → New query**, вставьте весь текст `mellon_club_applications.sql` и нажмите **Run**. Файл содержит сохранение анкеты (0013) и заявки в клуб (0014); нужны ранее установленные миграции 001–012.
4. В терминале выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_moy_prihod_club_registration.py
flutter pub get
flutter analyze
flutter test
```

Если файл скачался под другим именем, после `python3 ` перетащите его из Finder в терминал. Установщик делает резервную копию рядом с проектом и проверяет совместимость файлов до записи. При конфликте пришлите его вывод: локальные изменения он не перезаписывает.

5. После успешных проверок запустите:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Полный архив проекта содержит ту же миграцию в `supabase/migrations/202609120013_club_registration.sql` и миграцию заявок `202609120014_club_applications.sql`. Старый SQL обновления ролей повторно выполнять не требуется. SMTP и шаблоны писем продолжают использовать текущую настройку Supabase.

## Что изменено

- Нижняя навигация: **Лента / Молодёжный клуб / Карта**. Полное название переносится на маленьком экране; высота панели зависит от текста.
- Гость по нажатию центрального пункта видит модальное окно регистрации. Закрытие крестиком, нажатием снаружи или системным действием назад возвращает на исходную публичную страницу.
- Светлое оформление окна повторяет композицию референса: иллюстрация храма и пейзажа, заголовок PTSerif, спокойные голубые акценты, шесть полей, кнопка «Продолжить» и ссылка «Войти».
- Вместо телефона — **Email** с конвертом. Дата рождения выбирается в календаре. Пароль — минимум 12 символов, с повторным вводом и переключением видимости.
- Птицы пролетают через сцену, мягко движутся слой облаков и листья. Храм остаётся на месте. При системном сокращении анимации они неподвижны; после закрытия окна анимация освобождается.
- Публичные лента и существующий раздел карты остаются доступны без аккаунта. Карта в текущем проекте по-прежнему содержит прежний экран-заготовку; интеграция карт не входит в это обновление.
- Вошедший пользователь сразу открывает свой молодёжный клуб. Подтверждение регистрации использует существующий экран с кодом, ссылкой из письма и повторной отправкой.
- Имя, фамилия и дата рождения передаются при регистрации и сохраняются сервером в профиле. Пароль не сохраняется в метаданных. Регистрация создаёт ожидающую заявку в выбранный клуб и ожидающее вступление в приход, не выдавая роли и доступ к чатам. В том же окне форма плавно сменяется карточкой «Заявка отправлена». Кнопка «Понятно» закрывает окно.

## Проверка на вашем Mac

1. Выйдите из аккаунта. Откройте ленту и карту — запроса регистрации быть не должно.
2. Нажмите «Молодёжный клуб»: должно появиться одно окно с храмом. Закройте его — исходная вкладка должна остаться открытой.
3. Снова откройте окно. Проверьте прокрутку, календарь, видимость пароля, ошибки пустых полей и несовпадения паролей. При увеличении текста длинные подписи располагаются над полями, сохраняя полное название.
4. Зарегистрируйте новый тестовый аккаунт. Повторные нажатия во время запроса не должны отправлять новые запросы. После серверной ошибки текст должен оставаться доступен для редактирования.
5. Подтвердите почту через уже настроенное письмо или код. Откройте профиль и проверьте имя, фамилию и дату рождения.
6. Проверьте «Уже есть аккаунт? Войти»: прежний экран входа должен открыться, а успешный вход — привести в клуб.

## Проверки при подготовке

Проверены синтаксис Dart, форматирование, серверное сохранение анкеты, отсутствие выдачи ролей через метаданные, совместимость старой регистрации и повторное применение SQL. Пройдены 17 существующих серверных проверок ролей, чатов и приватности в локальном PostgreSQL PGlite с тестовой схемой Auth/Storage. Добавлены Flutter-тесты гостевой навигации, формы, повторного запроса после ошибки и закрытия во время отправки.

Flutter SDK в среде подготовки отсутствует, поэтому `flutter analyze`, `flutter test` и визуальную проверку Flutter в Chrome необходимо выполнить на вашем Mac. Проверка в PGlite не заменяет подтверждение реальной доставки письма в Supabase.

Использованы документированные механизмы [Supabase signUp](https://supabase.com/docs/reference/dart/auth-signup) и [Flutter showGeneralDialog](https://api.flutter.dev/flutter/widgets/showGeneralDialog.html).

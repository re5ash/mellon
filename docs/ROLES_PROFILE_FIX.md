# Исправление меню чата и экрана профиля

12 сентября 2026 года, после обновления ролей и профиля.

## Что исправлено

- Индикатор загрузки в чате появляется во время проверки прав, загрузки истории и выполнения действия. Во время выбора пункта меню или подтверждения удаления индикатор скрыт. Защита от повторного открытия меню и двойного выполнения действия сохранена.
- После выхода из аккаунта экран профиля скрывает личные данные и показывает кнопку «Войти», ведущую на экран авторизации.
- Существующие проверки удаления и закрепа сохранены. Добавлена проверка отложенного ответа: индикатор виден во время запроса, скрыт во время выбора, повторное нажатие не создаёт ещё один запрос.

## Установка поверх обновления ролей

Скачайте `fix_moy_prihod_roles_tests.py` в «Загрузки». Остановите приложение и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_moy_prihod_roles_tests.py
flutter analyze
flutter test
```

Установщик создаёт резервную копию, проверяет совместимость файлов, сохраняет локальную конфигурацию и допускает повторный запуск. Если файл изменён вручную и его версия неизвестна, установка остановится до записи. Это исправление не меняет зависимости, авторизацию или SQL. Повторно применять SQL для него не нужно.

После успешных проверок:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Проверьте в чате долгое нажатие → «Удалить сообщение» → «Отмена», затем откройте меню ещё раз. При выборе действия под меню не должна оставаться полоса загрузки.

## Проверка в среде подготовки

Проверены синтаксис и формат изменённых Dart-файлов, совместимость установщика, резервная копия, повторное применение и отказ при неизвестных изменениях. Flutter SDK здесь отсутствует: результат `flutter analyze` и `flutter test` требуется подтвердить на Mac. Ранее сообщённые 97 успешных и 3 неуспешных теста относятся к предыдущей версии обновления.

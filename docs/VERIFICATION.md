Выполнено **61 SQL-проверка**, включая применение шести миграций. Полный вывод находится в `docs/rls-test-results.txt`; тест повторяется командой `npm test` из `supabase/tests`.

В `test/` созданы проверки ограничения ключей/безопасных переходов/курсора ленты и формы авторизации при разных viewport, клавиатуре и увеличенном шрифте. Они **написаны, но не запускались**. Tree-sitter проверяет грамматику; WASM-версия dart_style форматирует исходники. Ни один из них не заменяет Dart analyzer или Flutter runtime.

## Следующий обязательный набор проверок

1. Установить указанный SDK, `flutter pub get`; зафиксировать transitive lock и Android runner.
2. `dart format lib test`, `flutter analyze`, `flutter test` и сборки Web/Android. Исправить несовместимости API/типов, если SDK их выявит.
3. Повторить RLS-сценарии через REST с реальными anon/user JWT. Убедиться, что ни один client SELECT не получает private profile или чужой приход.
4. Проверить две одновременные заявки/назначения/исключение: partial unique index и блокировки рассчитаны на гонки, но параллельный тест здесь не выполнялся.
5. Реальный Realtime reconnect, выход/бан и инвалидирование отображаемых данных, поведение Safari standalone и клавиатуры.

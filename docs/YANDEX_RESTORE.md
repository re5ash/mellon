# Mellon — возврат на Яндекс Карту

Этот установщик переключает саму подложку карты обратно на Яндекс, в том числе после OpenFreeMap. Исправления событий, фотографии внутри метки храма и загрузки фотографии клуба включены. Кнопки построения маршрута нет. Сохранённый ключ и настройки Supabase остаются в `config/development.json`.

## 1. Установить и проверить

Остановите запущенный Flutter клавишей `q`. Сохраните `restore_mellon_yandex.py` в «Загрузки» и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/restore_mellon_yandex.py && flutter pub get && flutter analyze && flutter test
```

Перед изменениями установщик сверяет известные версии файлов, создаёт резервную копию в соседней папке `moy_prihod_update_backups` и сохраняет последние исправления. При неизвестных ручных изменениях установка останавливается до записи. Повторная установка ничего не меняет.

## 2. SQL для событий — если ещё не выполняли

Для переключения подложки SQL не нужен. Для исправления отображения событий требуется прежний файл `supabase/updates/map_events_visible.sql`. Если его уже запускали и получили `Success`, пропустите этот шаг.

На Mac скопируйте его содержимое:

```bash
pbcopy < supabase/updates/map_events_visible.sql
```

Откройте ваш проект Supabase → SQL Editor → новый запрос, вставьте и нажмите Run. Этот запрос добавляет функцию чтения событий, сохраняя действующие правила доступа. Повторное выполнение допустимо.

## 3. Запустить локально

```bash
python3 tools/mellon_web.py run
```

Откроется Chrome с приложением на `http://localhost:8080`. Команда проверяет, что используется Яндекс и в сохранённых настройках есть ключ. Если ключ отсутствует, выполните `python3 tools/configure_yandex_map.py`, затем снова запустите приложение.

Сохранение ключа само по себе не меняет уже запущенную сборку. После изменения ключа нужен полный перезапуск.

## 4. Обновить прежнюю ссылку Netlify

Остановите локальный запуск клавишей `q` и выполните:

```bash
python3 tools/mellon_web.py build
open build
```

Откройте существующий сайт `eloquent-entremet-040562` в Netlify, раздел Deploys. Перетащите туда папку **web** из открывшейся папки **build**. Именно внутри `web` лежит `index.html`. Дождитесь завершения публикации. Откройте прежнюю ссылку и обновите страницу сочетанием `Cmd + Shift + R`.

Локальный запуск не обновляет сайт по публичной ссылке. При повторной публикации загружайте папку из только что завершившейся сборки.

## Проверить опубликованную версию

После успешной сборки команда создаёт файл `build/web/mellon-map-provider.json`. В нём нет ключей или настроек Supabase. Откройте:

https://eloquent-entremet-040562.netlify.app/mellon-map-provider.json

Должны быть поля `"provider": "yandex"` и `"revision": "yandex-restore-20260914"`, а также время новой сборки. Если файла нет или открывается само приложение, на сайт ещё не попала эта сборка. Если файл правильный, но открытая вкладка показывает старую карту, закройте её и проверьте сайт в приватном окне браузера.

Этот файл подтверждает версию опубликованной сборки. Доступность тайлов зависит от действующего ключа Яндекса и сети; сборка не подтверждает активацию ключа.

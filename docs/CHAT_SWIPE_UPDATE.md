# Плавное открытие чата и свайп назад

Обновление изменяет переписку и список чатов Mellon. Новых ролей, зависимостей или изменений базы данных нет.

## Что изменилось

- В клубе свайп пальцем слева направо возвращает из переписки к списку. Экран следует за пальцем. Короткий свайп или отмена возвращают переписку на место; достаточно длинный или быстрый — закрывают её. Вертикальная прокрутка сообщений и меню по долгому нажатию сохраняются.
- Открытие и завершение перехода занимают до 300 мс, с мягким замедлением. Содержимое чата не исчезает во время движения. Список сохраняется под ним, включая поиск и положение прокрутки. На широком экране он остаётся слева.
- Кнопка назад использует тот же переход. Системная кнопка назад сначала закрывает открытую переписку. Для чатов по отдельной ссылке `/chats/:id` используется Cupertino-переход с возвратом жестом от левого края.
- Убрана нумерация чатов; цветные иконки стали насыщеннее.
- Справа от названия показывается время сегодняшнего сообщения, «Вчера», день недели либо дата; для прошлых лет — дата с годом. Используется местное время устройства.
- Пузыри сообщений компактнее: системный шрифт без засечек, текст 16, имя автора 13, время 11. Размер текста по-прежнему учитывает настройки оформления и масштаб устройства. Своё имя «Вы» в исходящем пузыре не дублируется. Внутри истории добавлены разделители дней.
- Поле ввода оформлено мягкой капсулой. Длинные сообщения переносятся; время находится в отдельном месте и не перекрывает текст. Настройки фона, цветов и режима сообщений блоками продолжают работать.

## Установка

Скачайте `update_mellon_chat_swipe.py` в «Загрузки», остановите `flutter run` клавишей `q`, затем выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_chat_swipe.py
flutter analyze
flutter test test/chat_swipe_test.dart test/club_scroll_test.dart test/club_live_test.dart test/community_chat_test.dart test/message_removal_test.dart test/appearance_test.dart --reporter expanded
```

Установщик проверяет версии изменяемых файлов, создаёт резервную копию и не перезаписывает неизвестные локальные изменения. Повторный запуск безопасен. SQL выполнять не нужно.

## Проверка на телефоне

1. Откройте чат: сообщения и поле ввода должны двигаться одним слоем.
2. Проведите вправо примерно на четверть ширины и отпустите: чат должен вернуться. Текст черновика сохраняется при отмене жеста.
3. Проведите вправо больше трети ширины: откроется список. При отмене системного жеста переписка остаётся открытой.
4. Проверьте прокрутку сообщений вверх-вниз, меню по долгому нажатию и обычную кнопку назад.
5. Откройте чат из глубины длинного списка и вернитесь: положение списка сохраняется.
6. Проверьте крупный шрифт, разные темы оформления, даты и время справа.

Мобильный браузер может перехватывать жест непосредственно от края экрана для своей истории. Встроенный свайп переписки работает и при начале немного дальше от края.

## Проверки разработки

Добавлены проверки движения за пальцем, отмены и завершения жеста, вертикального скролла, сохранения состояния, режима уменьшения движения, закрытия во время анимации, дат и длинных сообщений. Проверки модерации не ослаблены. Нажатие назад в прежнем тесте прокрутки теперь ждёт кадра после `ensureVisible`.

В среде подготовки нет Flutter SDK: Flutter analyze, widget-тесты и измерение FPS здесь не запускались. Выполнены форматирование Dart, разбор синтаксиса, проверка ссылок импортов и установщика. Фактическую плавность нужно подтвердить на целевом телефоне в profile/release-сборке.

## Запуск и публикация

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

```bash
flutter build web --release --dart-define-from-file=config/development.json --dart-define=AUTH_REDIRECT_URL=https://eloquent-entremet-040562.netlify.app/
open build
```

Загрузите папку `web` в Deploys существующего проекта Netlify. Адрес сайта сохраняется.

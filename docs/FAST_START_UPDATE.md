# Запуск Mellon без заставки

Скачайте mellon_run_v3.py в «Загрузки». Остановите прежний локальный запуск нажатием Ctrl+C и выполните:

```sh
cd ~/Desktop/moy_prihod && python3 ~/Downloads/mellon_run_v3.py
```

Файл устанавливает изменения с резервной копией, выполняет flutter analyze,
готовит release-версию и автоматически открывает её в браузере.
Оставьте терминал открытым. Для остановки нажмите Ctrl+C.

Надписи «Mellon», «Загрузка…» и сообщение о затянувшемся старте удалены
со стартового экрана. Пока движок готовит первый кадр, виден только фон.
Таймера заставки и дополнительной задержки нет. Реальные ошибки запуска
доступны в консоли браузера.

Сохранены загрузка CanvasKit с того же адреса, отложенный полный шрифт эмодзи,
ранняя загрузка основного JavaScript и кэш версионированных файлов.
Локальный запуск не меняет настройки Netlify в _headers.
SQL и изменения настроек Supabase или Яндекс Карт не нужны.

Удаление надписи меняет внешний вид запуска, а не отменяет время загрузки
движка и кода. Первый запуск по сети зависит от подключения и устройства.
Обновление опубликованного сайта требует отдельной публикации.

Установщик сохраняет изменённые файлы в соседней папке
moy_prihod_update_backups. Неизвестные изменения вспомогательных файлов
не перезаписываются.

Проверка: установка поверх версии v2 и повторная установка; сохранение
настроек и отсутствие конфликта Cache-Control. В Chromium проверяется
отсутствие надписей до готовности первого кадра и после длительного ожидания
на тестовой веб-оболочке. Flutter engine в этой проверке заменён тестовым
загрузчиком; реальная проверка кода и сборка выполняются на вашем Mac.

# Mellon: события на карте, метка храма и фото клуба

## Установка

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_map_and_club_photo.py
flutter analyze
flutter test
pbcopy < supabase/updates/map_events_visible.sql
```

Откройте Supabase → SQL Editor → New query, вставьте скопированный текст (Cmd+V) и нажмите Run. Успешный результат — `Success. No rows returned`. Это новый небольшой запрос для чтения событий с карты. Он не меняет сохранение событий, участников или права доступа. Повторное выполнение безопасно. Предыдущая миграция `map_events.sql` должна быть уже установлена.

Затем перезапустите приложение:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

## Исправления

1. **События.** Раньше сервер возвращал только события, начинающиеся сегодня. Теперь метки показывают опубликованные будущие события, события сегодня и продолжающиеся многодневные события. Уже завершившиеся до сегодняшнего дня скрыты. Плашка «Сегодня» относится только к событиям, начинающимся сегодня по времени Калининграда. Кнопка календаря справа открывает список доступных событий и плавно перемещает карту к выбранной точке — в том числе если точка далеко за пределами текущего экрана. После сохранения формы карта обновляется. Черновики, отменённые события и события без флажка не отображаются. Закрытое событие видно только тем, кто имел доступ к нему ранее.

2. **Капля храма.** Фотография заполняет форму капли без отдельного овала и пустого хвостика. Фото, рамка и тень используют одинаковый контур и размер. Пропорции фотографии сохраняются; края обрезаются по форме.

3. **Фотография клуба.** При наличии пользовательского фото встроенная старая картинка больше не показывается во время загрузки или ошибки. Загрузка идёт напрямую из защищённого хранилища, без отдельного запроса временной ссылки. Полученное фото повторно используется из памяти: до четырёх изображений и 8 МиБ исходных данных, срок 10 минут. После успешной замены фото новое изображение подготовлено к показу до закрытия редактора. При изменении пути старое изображение не переходит в новое. Кэш очищается при смене аккаунта и обновлении членства; поздний ответ от прежнего аккаунта не сохраняется.

Первое открытие незагруженного фото всё ещё зависит от сети. Пока оно загружается, показывается спокойный фон того же размера; повторный вход в пределах кэша не требует повторного скачивания. Этот кэш в оперативной памяти, после полного закрытия приложения фото загружается снова.

Установщик подходит к Яндекс Карте (исходной и компактной версии) и OpenFreeMap. Выбранная подложка, её подпись, ключи и `config/development.json` сохраняются. SQL не выполняется автоматически. Перед записью проверяются версии всех файлов, создаётся резервная копия; неизвестные локальные изменения останавливают установку до записи.

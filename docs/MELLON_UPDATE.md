# Новое название — Mellon

Обновление меняет название приложения на **Mellon**: заголовок, имя вкладки браузера, экран загрузки, название Web-приложения на домашнем экране и страницу без подключения. Для Android обновляется подпись приложения в существующем AndroidManifest.xml, если Android runner уже создан, и настройка для будущей сборки.

Название Mellon используется везде в интерфейсе: в главной кнопке навигации, вкладке ленты, заголовках, поле профиля и кнопке «Открыть Mellon». Дизайн, иконки, учётные записи, права и данные сохраняются. Папку `moy_prihod`, Dart-пакет и идентификаторы приложения переименовывать не требуется; ссылки входа продолжают работать.

Ранее сохранённое стандартное имя автоматически отображается как Mellon. Собственное название, заданное суперадминистратором, сохраняет приоритет. В «Настройках приложения» можно сохранить Mellon и в серверной конфигурации. SQL для переименования не требуется.

## Установка

1. Скачайте обновлённый `update_moy_prihod_mellon.py` в «Загрузки», заменив предыдущий файл, если он уже есть.
2. Остановите запущенное приложение клавишей `q` в его терминале.
3. Выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_moy_prihod_mellon.py
flutter analyze && flutter test
```

Если файл сохранился в другую папку, напишите `python3 ` с пробелом и перетащите скачанный файл в терминал, затем нажмите Enter.

Установщик создаёт резервную копию. Настройки подключения и диагностические добавления в web/index.html сохраняются. При неизвестных изменениях в заменяемом Dart-коде установка останавливается до записи.

Также включено ранее подготовленное исправление завершения удаления при отключённой анимации, если оно ещё не установлено. Уже обновлённые файлы пропускаются.

Запустите приложение заново:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Если уже добавляли Web-приложение на домашний экран телефона, его прежняя подпись может сохраниться до обновления браузером. Для немедленного изменения подписи удалите старый ярлык и добавьте его заново. Страница без соединения получает новую версию кеша.

## Название в письмах

Локальные шаблоны уже содержат Mellon. Для писем, которые отправляет рабочий Supabase, изменения нужно отдельно сохранить в его панели: [настройки SMTP](https://supabase.com/docs/guides/auth/auth-smtp) и [шаблоны писем](https://supabase.com/docs/guides/auth/auth-email-templates).

- В настройках SMTP замените **Sender name** на `Mellon`.
- В **Confirm sign up** задайте тему `Mellon — подтверждение почты` и замените содержимое Body / Source на файл `supabase/templates/confirmation.html`.
- В **Reset password** задайте тему `Mellon — восстановление пароля` и замените Body / Source на `supabase/templates/recovery.html`.

Адрес отправителя, SMTP-пароль, домен и адреса возврата остаются прежними. Установщик не подключается к панели Supabase и не отправляет письма.

## Проверка

Проверены синтаксис изменённых Dart-файлов, значения Web-манифеста и заголовков, сохранность переменных и ссылок в письмах, повторная установка, резервная копия и сохранение локальных настроек. Flutter SDK в среде подготовки отсутствует: `flutter analyze` и `flutter test` запускаются на Mac.

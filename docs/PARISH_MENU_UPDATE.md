# Меню своего прихода по новому образцу

Обновление для версии, на которой пользователь подтвердил `flutter analyze: No issues found` и 48 прошедших Flutter-тестов.

## Реализовано

- Светлый голубой фон, белые округлые карточки, тёмно-синие заголовки, текст без засечек и цветные иконки. Палитра находится в `lib/design_system/parish_menu_theme.dart`, тёмная тема также предусмотрена.
- Карточка прихода: название и адрес из базы, кнопка «О приходе» непосредственно под названием. Пока фото не добавлено, показана нейтральная иконка храма.
- Ближайшее опубликованное событие из своего прихода: название, дата, время, краткое описание. Нажатие открывает раздел событий на той же странице.
- Меню в порядке **Чаты / Расписание / События / Помощь**. Сначала открыты чаты. Меню переключает содержимое внутри страницы, выделяет выбранный раздел и адаптируется к доступной ширине/размеру текста.
- Список доступных чатов с номерами, цветными значками и переходом в существующий чат. Поиск по названиям без учёта регистра; закрытие поиска снимает фильтр. До 50 чатов в рамках текущего репозитория.
- «Помощь» на странице прихода запрашивает записи только этого прихода. Общая вкладка помощи в ленте сохраняет свой общий запрос. RLS остаётся на сервере.
- Верхняя панель: иконка храма, «Mellon», уведомления и меню с тремя точками. В меню доступны профиль и, при наличии разрешений, «Управление».
- Нижние направления: Лента / Mellon / Карта. На широком экране сохраняется боковая навигация. Стрелка возврата продолжает обновляться при переходах.

В базу не добавляются демонстрационные чаты из картинки. На экране отображаются существующие чаты, доступные аккаунту. Имя настоятеля, фотография храма, закладки и показатели непрочитанного не вымышлены: их хранения/редакторов пока нет. Эти элементы потребуют отдельного расширения данных. Расписание пока является хронологическим списком событий, без редактора повторяющихся богослужений. Поэтому оформление следует образцу, но изображение не воспроизводится полностью с демонстрационным содержимым.

## Установка

1. Скачайте `update_moy_prihod_parish_menu.py`.
2. В **терминале VS Code**, в папке `moy_prihod`, остановите Flutter клавишей `q`, если он запущен. Дождитесь приглашения командной строки.
3. Напечатайте `python3` и пробел. Перетащите новый скачанный файл из Finder в терминал и нажмите Enter.
4. После успешной установки выполните:

```bash
flutter analyze
flutter test
```

5. После успешных проверок:

```bash
flutter run -d chrome --web-port=8080 --dart-define-from-file=config/development.json
```

`supabase db push` и повторный bootstrap не требуются: миграции, конфигурация подключения и зависимости не менялись. Установщик создаёт резервную копию рядом с проектом, проверяет совместимость и сохраняет локальные настройки. При конфликте исходников ничего не записывает — пришлите его вывод.

## Что проверить в приложении

- Откройте «Mellon»: порядок карточек и цветных разделов, поиск по реальным чатам.
- Переключите все четыре раздела. Помощь и события должны относиться к своему приходу.
- Откройте «О приходе» и вернитесь стрелкой. Откройте существующий чат и вернитесь.
- Меню с тремя точками → «Управление» доступно только аккаунтам с разрешениями.
- Проверьте узкое окно, увеличенный текст и обе темы. Финальная проверка Safari/PWA проводится на реальном iPhone через HTTPS.

В среде подготовки проверены Dart-синтаксис, относительные импорты, неизменность восьми миграций, упаковка и установщик. Добавлены проверки меню и поиска чатов; сохранены проверки возврата и адаптивности. **Flutter SDK здесь отсутствует, поэтому новые analyze/test ещё нужно выполнить на Mac.** Прежние 48 успешных тестов относятся к версии до этого обновления.

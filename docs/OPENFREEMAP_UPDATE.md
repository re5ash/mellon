# Mellon — OpenFreeMap

Установить после обновления Яндекс Карты. Подходит и для исходной, и для компактной подписи Яндекса.

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_openfreemap.py
flutter pub get
flutter analyze
flutter test
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

## Что изменилось

- Подложка — векторные данные OpenFreeMap, отрисованные средствами Flutter. Регистрация и API-ключ не нужны.
- Светлый стиль Mellon Light на основе Positron. Для названий выбран русский язык, если он есть в данных; иначе используется местное название. Шрифт входит в приложение.
- Метка храма, жесты, масштабирование, карточки, геолокация и события сохранены. Выбор точки администратором тоже использует OpenFreeMap.
- Вместо логотипа Яндекса — небольшие ссылки © OpenStreetMap и © OpenMapTiles. Информация о стиле и лицензия доступны через «О карте».
- «Поделиться» передаёт ссылку OpenStreetMap на выбранную точку. Построение маршрутов не добавляется.
- Загрузка стиля приложения не зависит от отдельного сервера стилей. Актуальный адрес набора карт запрашивается по `https://tiles.openfreemap.org/planet`; дата набора не зашита в код.
- Повторная загрузка после сетевой ошибки запускается нажатием на сообщение. Она сохраняет положение камеры. Для запроса установлен тайм-аут 20 секунд с отменой; бесконечных автоматических повторов нет.
- Отрисованные фрагменты повторно используются при движении карты. Библиотека также ограничивает локальное хранилище векторных фрагментов 20 МиБ и сроком 7 дней. Полноценный режим карты без интернета не реализован: при новом запуске нужен доступ к описанию набора.

SQL повторно выполнять не нужно. `config/development.json`, ключи Supabase и данные чатов установщик не меняет. Старый ключ Яндекса больше не используется картой; повторно запускать `tools/configure_yandex_map.py` не нужно. Старые файлы Яндекса оставлены на диске для совместимости с установленными обновлениями, но новый экран их не вызывает.

## Обновление публичной ссылки

```bash
cd ~/Desktop/moy_prihod
flutter build web --release --dart-define-from-file=config/development.json --dart-define=AUTH_REDIRECT_URL=https://eloquent-entremet-040562.netlify.app/
open build
```

На существующем сайте Netlify откройте **Deploys** и загрузите папку `build/web`. Используйте существующий сайт, чтобы адрес не изменился. После успешной публикации обновите вкладку браузера: Cmd+Shift+R. Простая локальная сборка сама сайт не публикует.

## Проверка и ограничения

До выдачи установщика выполняются анализатор, тесты приложения и release-сборка web. Тесты сетевого слоя используют контролируемые ответы: успешная загрузка TileJSON, ошибка HTTP, тайм-аут, повтор. Отдельный тест действительно отрисовывает векторный фрагмент по новому стилю и проверяет воду и здания. Файл `test/fixtures/map_synthetic.pbf` — искусственный фрагмент для теста, не реальная карта Калининграда.

Живую загрузку фрагментов OpenFreeMap в среде подготовки подтвердить не удалось: сервер ограничил доступ из этой среды. Поэтому после установки нужно проверить карту в вашем Chrome и по публичной ссылке. Прохождение тестов не является подтверждением доступности внешнего сервиса у каждого пользователя.

При ошибке откройте в обычном браузере `https://tiles.openfreemap.org/planet`. Там должен открыться JSON с полем `tiles`. Если появляется ошибка, пришлите её текст вместе с выводом Flutter; ключи передавать не нужно.

OpenFreeMap предоставляет публичный бесплатный сервис без ключей; гарантии бесперебойной работы нет. Условия: https://openfreemap.org/ и https://openfreemap.org/quick_start/.

Стиль: https://github.com/hyperknot/openfreemap-styles/tree/main/styles/positron. Исходная лицензия сохранена в `assets/map/OPENFREEMAP_STYLE_LICENSE.md`. Изменены подписи, шрифты и значки; отдалённые наборы спрайтов и шрифтов не загружаются.

## Откат

Установщик проверяет известные версии файлов до записи и делает резервную копию в соседней папке `moy_prihod_update_backups`. При сбое записи уже изменённые файлы восстанавливаются. Повторный запуск установленного обновления ничего не перезаписывает. Если обнаружены неизвестные локальные правки, установка останавливается до изменений.

# Технические источники

Просмотрены 10 сентября 2026. Источники обосновывают выбранные платформенные подходы; они не подтверждают, что этот проект уже собран или проверен на устройстве.

- Разделение UI/data, репозитории и маршрутизация: [Flutter architecture recommendations](https://docs.flutter.dev/app-architecture/recommendations).
- Safari/Web, кэширование и service worker: [Flutter Web FAQ](https://docs.flutter.dev/platform-integration/web/faq).
- Гранты и политики доступа: [Supabase Row Level Security](https://supabase.com/docs/guides/database/postgres/row-level-security).
- Публичные/секретные ключи: [Supabase API keys](https://supabase.com/docs/guides/getting-started/api-keys).
- Подписки с RLS: [Supabase Postgres Changes](https://supabase.com/docs/guides/realtime/postgres-changes).
- Установка и Web Push на iPhone: [WebKit Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).
- Просмотренные прямые версии пакетов: [flutter_riverpod](https://pub.dev/packages/flutter_riverpod), [go_router](https://pub.dev/packages/go_router), [supabase_flutter](https://pub.dev/packages/supabase_flutter), [shared_preferences](https://pub.dev/packages/shared_preferences).

- Жизненный цикл провайдеров и обновление данных: [Riverpod Refs](https://riverpod.dev/docs/concepts2/refs).
- Поле выбора текущего Flutter: [DropdownButtonFormField](https://api.flutter.dev/flutter/material/DropdownButtonFormField-class.html).
- Коды ошибок регистрации и лимитов: [Supabase Auth error codes](https://supabase.com/docs/guides/auth/debugging/error-codes), [AuthException API](https://pub.dev/documentation/gotrue/latest/gotrue/AuthException-class.html).

- [Supabase Database Functions](https://supabase.com/docs/guides/database/functions) — функции, search_path и права EXECUTE.
- [Supabase Flutter RPC](https://supabase.com/docs/reference/dart/rpc) — вызов серверной функции из Dart.

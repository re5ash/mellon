# Mellon — блоки 5 и 6

## Установка

1. Скопируйте весь файл `feed_publications.sql` в Supabase → SQL Editor → New query → Run. Достаточно одного запроса; повторное выполнение допускается.
2. Сохраните `update_mellon_feed_publications.py` в «Загрузки».
3. Выполните:

```bash
cd ~/Desktop/moy_prihod && python3 ~/Downloads/update_mellon_feed_publications.py
```

Установщик создаёт резервную копию, проверяет исходники, выполняет тесты новых функций и открывает локальное приложение в Chrome. Терминал оставьте открытым; Ctrl+C остановит локальный сервер.
Для повторного запуска используйте ту же команду. Повторная установка не перезаписывает уже обновлённые файлы.

## Что изменено

- Фото занимает 48% ширины верхней части карточки. Градиент и мягкое размытие стыка создаются приложением; оригинальную фотографию обрабатывать не нужно.
- Название и начало описания находятся слева. «Подробнее» открывает продолжение на полную ширину ниже верхнего блока; фото не растягивается. Анимация укладывается в 360 мс. Учитывается уменьшение движения.
- В событиях и расписании доступны фото, дата и время, место, выбор иконки и раздел «Публикация».
- Переключатель «Опубликовать в общей ленте» при создании выключен. Автоматический подбор иконки работает локально по русскому названию и описанию; ручной выбор сохраняется.
- Общая лента читает исходную запись события/расписания через представление базы. Копия в posts не создаётся. Изменение, отключение публикации и удаление отражаются в ленте.
- Уведомление об изменении ленты не содержит текстов записей; оно позволяет обновить другие устройства даже после скрытия события правилами доступа. Резервное обновление — раз в 15 секунд.
- Фото автоматически уменьшается до 1200 пикселей по длинной стороне без искажения пропорций, сохраняется в закрытом хранилище и выдаётся по временной ссылке. Ранее полученная ссылка может оставаться действительной до часа; скрытие карточки обновляется отдельно.
- Ключи, карта, чаты, аватар клуба и быстрый запуск сохраняются. Установщик не публикует сайт.

## Проверка после установки

В каждом из разделов «События» и «Расписание»: создать запись с выключенной публикацией → проверить отсутствие в общей ленте → включить публикацию → отредактировать текст и иконку → выключить публикацию → включить снова → удалить. На каждом шаге проверить обе выдачи. Проверить обычную фотографию и ручной выбор иконки. Раскрыть длинное описание, прокрутить ленту, свернуть его; проверить на телефоне.

Проверены SQL-сценарии на изолированной базе PostgreSQL/PGlite с миграциями этого проекта: повтор установки, права, публикация, отсутствие дублей, редактирование, конфликт версий, скрытие, удаление, доступ к фото, уведомление об изменении ленты и курсорная пагинация. Flutter SDK в среде подготовки отсутствует; `flutter analyze` и тесты интерфейса запускаются установщиком на Mac.

# Исправление кнопки «Продолжить»

В предыдущей версии кнопка становилась неактивной, если список клубов ещё загружался, возвращал ошибку или был пустым. В этой версии она реагирует на нажатие и объясняет причину. Кнопка отключается только на время отправки регистрации; повторное нажатие не отправляет дубликат.

Если загрузка не удалась, «Продолжить» повторяет её. Введённые поля сохраняются. Ожидание ответа списка ограничено 15 секундами. После успешной загрузки повторное нажатие отправляет корректно заполненную форму.

## Установка

Остановите Flutter клавишей `q`, скачайте `fix_mellon_continue_button.py` в «Загрузки» и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_continue_button.py
flutter analyze
flutter test
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

## Если заявка всё ещё не отправляется

- «Приём заявок пока не настроен»: в Supabase вашего проекта выполните ранее выданный файл `mellon_club_applications.sql` полностью через SQL Editor. Затем обновите список клубов в форме.
- «Сейчас нет доступных клубов»: администратор должен создать молодёжный клуб в опубликованном приходе; клуб не должен быть архивным. Затем нажмите «Обновить список клубов». Установщик не создаёт фиктивных приходов или клубов.
- «Список клубов ещё загружается»: дождитесь результата; при тайм-ауте проверьте соединение и повторите загрузку.
- «Проверьте отмеченные поля выше»: прокрутите форму к полям с ошибками, исправьте их и повторите нажатие.

Без выбранного доступного клуба нельзя достоверно отправить заявку руководителю. Успешная карточка по-прежнему появляется только после серверного подтверждения записи заявки.

Изменений схемы базы в этом исправлении нет. Настройки входа, восстановление пароля и анимация сцены сохраняются. Установщик сохраняет резервные копии и не перезаписывает неизвестные локальные изменения.

Проверены синтаксис Dart и установка на копии последней версии, повторный запуск, резервные копии и защита локальных правок. Добавлены Flutter-тесты пустого списка, ожидания, ошибки загрузки и повторного нажатия. Flutter SDK здесь недоступен: анализатор и Flutter-тесты необходимо запустить на Mac.

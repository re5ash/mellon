# Mellon: свайп назад в веб-версии на iPhone

## Что исправлено

На записи при жесте вправо поверх чата появлялись снимки карты и ленты. Это похоже на одновременное выполнение жеста истории Safari/PWA и анимации возврата Flutter. Прежнее обновление изолировало внутренние маршруты Flutter, но не отменяло действие браузера.

Теперь открытый `MellonChatRoute` включает отдельную защиту браузерного жеста. На документе временно устанавливается `overscroll-behavior-x: none`. Обработчик `touchstart` с `passive: false` отменяет стандартное действие только для одиночного касания у левого или правого края (32 CSS-пикселя). События продолжают передаваться Flutter: обработчик не вызывает `stopPropagation`, не создаёт второй возврат и не меняет историю браузера.

Защита действует до завершения закрывающей анимации маршрута. После закрытия последнего чата обработчик удаляется, прежние стили восстанавливаются. Касания в середине, масштабирование двумя пальцами и обычные разделы не перехватываются. Для нативного приложения браузерный мост не используется. Если старая HTML-страница ещё находится в кэше и мост отсутствует, чат продолжает работать без ошибки.

Основание решения: [Apple — Handling Events](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/HandlingEvents/HandlingEvents.html), [W3C — Overscroll Behavior](https://www.w3.org/TR/css-overscroll-1/), [обсуждение конфликта жестов PWA](https://github.com/w3c/pointerevents/issues/358).

## Установка

Исправление устанавливается поверх `update_mellon_club_stories.py`. Сохраните `fix_mellon_iphone_chat_swipe.py` в «Загрузки». Остановите Flutter клавишей `q`, если он запущен.

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_iphone_chat_swipe.py && flutter analyze && flutter test
```

Установщик проверяет исходные файлы и создаёт резервную копию рядом с проектом. При неизвестных изменениях ничего не записывается. Повторная установка безопасна. Нового SQL и повторного ввода ключей не требуется.

Локальная проверка:

```bash
cd ~/Desktop/moy_prihod
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Затем `q`, сборка и обновление **существующего** сайта Netlify:

```bash
cd ~/Desktop/moy_prihod
flutter build web --release --dart-define-from-file=config/development.json --dart-define=AUTH_REDIRECT_URL=https://eloquent-entremet-040562.netlify.app/
open build
```

Перетащите папку `web` в Deploys существующего сайта. Дождитесь завершения публикации. На iPhone полностью закройте Mellon через переключатель приложений и откройте снова. В Safari обновите страницу. Для исправления нужны новая HTML-страница, новый файл `mellon_chat_gestures.js` и новая сборка Flutter — загружайте всю папку `build/web`.

Проверьте на телефоне: сначала откройте карту, затем клуб и чат. Выполните короткий отменённый свайп от левого края и полный свайп назад. Под движущимся чатом должен оставаться список чатов. Карта и лента не должны появляться. Из середины экрана возврат не выполняется.

## Проверено и ограничения

- Анализ Dart, тесты чата на узком/широком экране, отмены жеста, позиции списка и открытия без ожидания сети.
- JS-обработчик и скомпилированный Dart/JS-мост проверены в Node: края, середина, несколько пальцев, передача событий дальше, восстановление стилей, вложенные маршруты, повторное освобождение и отсутствие моста в старом HTML.
- Сборка Flutter Web release.

Тесты Node проверяют обработчики, но не эмулируют системную анимацию WebKit. Фактическое поведение жеста Safari/PWA нужно подтвердить на iPhone после публикации; физического iPhone в среде проверки нет.

Разработчику, дополнительная проверка:

```bash
dart compile js --enable-asserts tools/test_browser_chat_bridge.dart -o /tmp/mellon_chat_bridge_test.js
node tools/test_browser_chat_gestures.mjs /tmp/mellon_chat_bridge_test.js
```

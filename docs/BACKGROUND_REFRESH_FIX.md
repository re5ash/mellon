# Mellon — плавное фоновое обновление

Исправлена обнаруженная причина скачков содержимого: периодическая проверка прав вызывала повторную загрузку экрана клуба и списков управления с заменой содержимого индикатором загрузки.

Теперь уже загруженные данные остаются на экране во время фонового запроса. Поиск и положение прокрутки сохраняются. Проверки прав продолжают выполняться: изменение роли в клубе обновляет доступные кнопки, даже если глобальная роль пользователя осталась прежней. При отказе сервера прежнее содержимое убирается и показывается ошибка. Смена аккаунта по-прежнему очищает данные предыдущего пользователя.

Повторное событие авторизации с тем же ID пользователя больше не считается сменой аккаунта. Маршрутизатор не обновляет маршрут при каждом одинаковом ответе о правах; ограничение доступа гостю продолжает обрабатываться.

В установщик также включено ранее подготовленное исправление пунктов «Настройки», «Управление» и «Выйти». Уже установленная часть повторно не записывается.

## Установка и проверка

Скачайте `fix_mellon_background_refresh.py` в «Загрузки». Выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_background_refresh.py
flutter analyze
flutter test test/background_refresh_test.dart test/account_menu_test.dart --reporter expanded
```

Установщик проверяет известные версии файлов и создаёт резервную копию в соседней папке `moy_prihod_update_backups`. Неизвестные изменения в затрагиваемых файлах останавливают установку. Повторный запуск безопасен. SQL выполнять не нужно.

После целевых тестов выполните полный набор `flutter test`.

Для проверки локально:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Откройте клуб, включите поиск чата, введите часть названия и прокрутите страницу. Оставьте её открытой хотя бы на минуту: фоновые проверки не должны заменять содержимое индикатором загрузки или сбрасывать поиск. Отдельно проверьте смену клубной роли вторым администратором: после очередного ответа сервера кнопки управления должны соответствовать новым правам.

## Версия по ссылке

Для Netlify нужно собрать новую веб-версию с тем же файлом конфигурации, который использовался при последней публикации, и загрузить обновлённую папку `build/web` в существующий проект. Ссылка для друга останется прежней. Затем обновите страницу приложения на обоих устройствах.

## Границы проверки

В среде подготовки проверяются синтаксис Dart, импорты, сохранность остальных файлов и работа установщика. Flutter SDK здесь отсутствует: `flutter analyze` и тесты необходимо запустить на Mac. Добавлены регрессионные сценарии для фонового обновления, смены прав, повторного события той же сессии, отказа сервера, смены аккаунта и запоздавшего ответа прежней сессии.

Интервал около пяти секунд на устройстве пользователя здесь не воспроизводился. Исправление устраняет найденную в коде причину скачков при обновлении данных; если скачки сохранятся после обновления опубликованной сборки, потребуется короткая запись экрана с указанием открытого раздела.

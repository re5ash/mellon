# Mellon: полноэкранные чаты и истории клуба

## Установка на Mac

Сохраните `update_mellon_club_stories.py` в «Загрузки». Если Flutter запущен, остановите его клавишей `q`.

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_club_stories.py && flutter pub get && flutter analyze && flutter test
```

Установщик проверяет исходные файлы до записи. Неизвестные изменения останавливают установку целиком. Резервная копия создаётся рядом с проектом в `moy_prihod_update_backups`. Повторный запуск безопасен. Настройки подключения, ключ карты и выбранная карта сохраняются.

## SQL для Supabase

Нужен один новый запрос поверх ранее установленной базы Mellon, включая права на фотографию клуба. Откройте Supabase → ваш проект → SQL Editor → New query. Вставьте **весь** файл `supabase/updates/club_stories.sql` и нажмите Run. Отдельный `mellon_club_stories.sql` содержит тот же запрос.

Скопировать SQL на Mac:

```bash
cd ~/Desktop/moy_prihod
pbcopy < supabase/updates/club_stories.sql
```

`Success. No rows returned` означает успешное выполнение. Не вставляйте команды Python или Flutter в SQL Editor. Повторно выполнять старые миграции карты не требуется. Новый SQL не удаляет переписку, события или фотографии клуба. Создаются таблица историй, приватный Storage bucket, политики доступа, функции публикации/очистки и подписка Realtime.

## Поведение

- Чат открывается непрозрачным экраном в корневом Navigator. Панель разделов и карточка клуба находятся под закрытым маршрутом и не получают жесты. Внешних скруглений у чата нет.
- Свайп вправо от самого левого края ведёт только назад, к сохранённому списку чатов. Короткий жест можно отменить; он сохраняет черновик. Свайп из середины не переключает разделы. Действуют кнопка назад и системный возврат.
- Аватар клуба круглый. Редактор сохраняет квадратное изображение 1024×1024, круг применяется при отображении; исходное соотношение сторон не растягивается. Фоновая фотография не используется. Тексты остаются, кнопка «Ещё» не добавляется.
- У администратора нажатие на аватар показывает карандаш и плюс. Карандаш открывает редактор фотографии. Плюс предлагает фото или видео, затем полноэкранный предпросмотр и явную кнопку «Опубликовать».
- После публикации вокруг аватара появляется кольцо. Нажмите кольцо для просмотра; обычный участник может также нажать сам аватар. У администратора повторное нажатие на аватар после появления кнопок открывает истории.
- Истории доступны участникам клуба 24 часа. Фото показывается 5 секунд, видео — до окончания. Тап слева возвращает к предыдущей истории, справа — к следующей. Удержание ставит на паузу, свайп вниз закрывает. Видео первоначально без звука, есть кнопка звука.
- Видео ограничено 60 секундами и 50 МБ; поддерживаемость кодеков зависит от устройства/браузера. Если файл не удаётся открыть в предпросмотре, публикация недоступна. Для совместимости используйте MP4/H.264. Новая съёмка камерой и видеокружки этим обновлением не добавляются.

## Хранение и доступ

Публиковать могут пользователи с тем же правом, что и смена фотографии данного клуба. Права проверяются на сервере, а не только видимостью кнопок. Гости и участники другого клуба не читают истории. Storage приватный; ссылки на медиа временные. После изменения аккаунта прежние истории скрываются.

Повторная отправка после ошибки использует тот же идентификатор публикации и не создаёт дубликатов. Опубликованные истории хранятся в Supabase и доступны с другого устройства. Через 24 часа SQL закрывает обычный доступ. Физические файлы просроченных публикаций удаляются через Storage API после следующей успешной публикации администратором; при отсутствии новых публикаций или ошибке сети они могут остаться в Storage. Отдельная плановая серверная очистка ещё не настроена. Незавершённая загрузка при закрытии приложения также может оставить неопубликованный файл для последующей уборки.

## Проверка

Проверки охватывают полноэкранность на узком и широком экранах, изоляцию жестов, отмену свайпа, положение списка, предпросмотр фото/видео, ограничение длительности, повтор публикации и просмотр/закрытие историй. SQL проверяется на локальном PostgreSQL-совместимом PGlite с ролями, RLS, повторной установкой и очисткой через Storage. Это не заменяет проверку реального Storage и воспроизведения на телефоне после установки.

```bash
flutter analyze
flutter test
```

Для разработчика: `supabase/tests/club_stories_integration.mjs` запускается с установленным `@electric-sql/pglite` через переменную `PGLITE_MODULE`, указывающую на его `dist/index.js`. Документация видеоплеера: https://pub.dev/packages/video_player .

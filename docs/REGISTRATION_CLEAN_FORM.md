# Mellon: регистрация без списка клубов

Из формы убраны карточка «Молодёжный клуб: …» и выпадающий список клубов. Под подтверждением пароля располагается кнопка «Продолжить» с обычным отступом. Пустое место от карточки не сохраняется. Названия клубов и приходов не выводятся в этой форме, включая сообщения о загрузке и ошибках.

Если доступен один клуб, заявка направляется в него автоматически, как раньше. Успех показывается только после подтверждения записи заявки сервером. Восстановление полей после ошибок, фон, анимация и экран отправленной заявки сохранены.

Если в дальнейшем появится несколько клубов, точку входа необходимо связать с конкретным клубом через параметр `youthId` у `openClubRegistration` / `ClubRegistrationDialog`. Без однозначного назначения форма сообщает о временной недоступности приёма заявок; случайный клуб не выбирается. Это изменение интерфейса регистрации, а не изменение прав доступа к каталогу API.

## Установка

Скачайте `update_mellon_registration_clean_form.py` в «Загрузки». Остановите запущенное приложение клавишей `q` в терминале, затем выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_registration_clean_form.py
flutter analyze
flutter test
```

После успешных проверок:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Установщик сохраняет резервную копию и проверяет совместимость файлов. SQL повторно выполнять не нужно.

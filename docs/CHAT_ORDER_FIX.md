# Исправление порядка чатов

Исправлена сортировка пользовательского меню «Mellon → Чаты». Теперь меньшее число означает более высокое положение: «Объявления» с порядком 30 располагаются выше «Болталки» с порядком 40. При одинаковом числе сравниваются названия по возрастанию, затем UUID для устойчивого порядка.

Причина: в Dart/PostgREST 2.9.1 метод `order` по умолчанию использует убывание. В запросе комнат явно добавлено `ascending: true` для sort_order, title и id. Прежняя SQL-проверка сама использовала ORDER BY по возрастанию и не проверяла направление, формируемое Dart-клиентом; поэтому она не выявила эту ошибку.

Источник: [документация PostgrestTransformBuilder.order](https://pub.dev/documentation/postgrest/latest/postgrest/PostgrestTransformBuilder/order.html).

## Установка

1. Скачайте `fix_moy_prihod_chat_order.py`.
2. В **терминале VS Code**, в папке `moy_prihod`, остановите запущенный Flutter клавишей `q`. Дождитесь приглашения командной строки.
3. Напечатайте `python3` и пробел, перетащите новый скачанный файл из Finder в терминал и нажмите Enter.
4. После успешной установки выполните в том же терминале:

```bash
flutter analyze
flutter test
```

5. При успешных проверках запустите:

```bash
flutter run -d chrome --web-port=8080 --dart-define-from-file=config/development.json
```

6. В Chrome откройте «Mellon → Чаты». Убедитесь, что «Объявления» (30) выше «Болталки» (40). Измените «Болталке» порядок на 20, сохраните: теперь она должна стать выше «Объявлений».

Новая миграция не нужна: `npx supabase db push` не требуется. Существующие числа в базе сохраняются. Установщик проверяет совместимость исходников, создаёт резервную копию и поддерживает повторный запуск. При конфликте пришлите вывод установщика.

Панель «Управление → Чаты и каналы» в этой версии по-прежнему использует отдельную постраничную выдачу по UUID; поле «Порядок» управляет именно меню прихода.

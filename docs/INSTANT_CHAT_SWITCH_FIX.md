# Mellon — мгновенное переключение чатов

Это исправление устанавливается поверх update_mellon_chat_emoji.py и заменяет описанное в предыдущем обновлении ожидание предварительной загрузки комнаты.

## Поведение

Нажатие на строку сразу выбирает чат. Название и описание берутся из уже загруженного списка. Фон и поле ввода остаются на своих местах, пока сервер возвращает сведения о комнате, права и сообщения. Данные списка используются только для отображения: отправка и выбор эмодзи включаются после подтверждения доступа. Сообщения загружаются внутри выбранной переписки.

Запоздалый ответ другой комнаты не меняет выбор. При ошибке загрузки выбранный чат остаётся открытым со своим названием, фоном и кнопкой «Повторить». Свайп назад и возвращение к позиции списка сохраняются. Переключение между уже открытыми комнатами не ждёт анимации открытия панели.

## Установка на Mac

Сохраните fix_mellon_instant_chat_switch.py в папку Downloads, затем выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_instant_chat_switch.py && flutter analyze && flutter test
```

Установщик проверяет версии всех изменяемых файлов до записи и создаёт резервную копию рядом с проектом. Повторный запуск ничего не перезаписывает. Если файлы изменены после предыдущего обновления, установка остановится и назовёт их.

Перезапустите локальную веб-версию:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Для опубликованного сайта потребуется обычная повторная release-сборка и загрузка build/web в существующий проект Netlify. Этот установщик обновляет локальные исходники.

## Проверка

Проверки с искусственно задержанными ответами сервера подтверждают выбор чата уже на следующем кадре, неизменные размеры области переписки и поля ввода, сохранение элемента фона на этапах загрузки, обработку поздних ответов и запрет отправки без прав. Отдельно проверяется первое открытие на экране 390×844.

Время получения самих сообщений зависит от сети. Исправление убирает ожидание сети перед отображением выбранной комнаты; реальную плавность на Mac нужно оценить после установки.

Новых зависимостей, изменений конфигурации подключения и SQL-миграций нет. Набор эмодзи из предыдущего обновления сохраняется.

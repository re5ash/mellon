# Плавное открытие и возврат из чата

Скачайте `fix_mellon_chat_motion.py` в «Загрузки», остановите прежний локальный
сервер через Ctrl+C и выполните:

```sh
cd ~/Desktop/moy_prihod && python3 ~/Downloads/fix_mellon_chat_motion.py
```

Установщик делает резервную копию, запускает `flutter analyze`, тесты переходов,
полноэкранного чата и медленного получения данных, затем открывает приложение
локально на Mac. SQL не требуется. Публикации в Netlify нет.

Вход в чат: 340 мс с плавным началом и завершением. Выход по стрелке: 280 мс.
Двигается только полноэкранный непрозрачный чат. Страница клуба, положение списка
и нижняя навигация остаются на месте. Верхняя кнопка клуба не подменяется стрелкой
из-за открытия чата поверх неё.

Сохранён встроенный в Flutter механизм Cupertino для свайпа от левого края,
его отмены и завершения. Во время жеста положение соответствует пальцу без
дополнительного преобразования кривой. Отмена сохраняет виджет чата и черновик.
Движение в середине чата не переключает разделы. Учтено уменьшение анимаций.

Браузерный обработчик защищает жест чата от одновременного перехода назад
в истории WebKit. Если он уже подключён, повторный тег не добавляется.
При необходимости в существующий `web/index.html` добавляется только подключение
этого локального скрипта; быстрый запуск и его кэш остаются прежними.

Обновление адреса клуба, карты и анимаций нижних иконок сохраняется. Данные чатов,
права, фото, история сообщений и настройки сервера этим исправлением не меняются.

Проверки установщика выполнены отдельно. В среде подготовки нет Flutter SDK:
анализатор и реальные Flutter widget tests выполняются на Mac перед запуском.
Частоту кадров на iPhone нужно оценить на самом устройстве после вашей публикации.

Справка Flutter о разделении визуального перехода и жеста:
[CupertinoRouteTransitionMixin.buildPageTransitions](https://api.flutter.dev/flutter/cupertino/CupertinoRouteTransitionMixin/buildPageTransitions.html),
[PageRoute](https://api.flutter.dev/flutter/widgets/PageRoute-class.html).

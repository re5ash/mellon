# Три темы Mellon

## Установка и запуск на Mac

Сохраните `update_mellon_themes.py` в «Загрузки» и выполните:

```bash
cd ~/Desktop/moy_prihod && python3 ~/Downloads/update_mellon_themes.py
```

Установщик проверяет версии изменяемых файлов, сохраняет резервную копию,
устанавливает оформление, выполняет `flutter analyze`, тесты настроек,
тем, клуба и навигации, затем собирает и открывает локальный просмотр.
Терминал нужно оставить открытым. Остановка: Ctrl+C.

SQL не требуется. По умолчанию загрузки на сайт нет.
Если ваш файл отличается от проверенной версии, установщик остановится до
изменений; не отключайте эту проверку — требуется совместить актуальный исходник.

Только установка без сборки/запуска:

```bash
cd ~/Desktop/moy_prihod && python3 ~/Downloads/update_mellon_themes.py --install-only
```

## Использование

«Оформление» → «Выбор темы» → выбрать один из трёх вариантов → «Готово».

- «Соборное стекло»: тёплая архитектура, заголовки PT Serif, спокойное стекло,
  круглые иконки, календарная дата ближайшего события.
- «Золотой свет»: светлый фон, золотой ободок, цветные круглые значки,
  объединённая поверхность списка чатов, компактные кнопки.
- «Небесный ореол»: голубой фон, золотисто-белый ореол, цветные иконки,
  отдельные стеклянные строки и светящаяся активная капсула.

До первого выбора остаётся текущее оформление. Нажатие на превью само по
себе ничего не сохраняет. «Отмена» закрывает черновик. При ошибке записи
показывается сообщение и возможность повторить сохранение.

Темы светлые: применение выбирает дневной режим и фон выбранной темы.
После этого можно самостоятельно включить тёмный режим, изменить акцент
или выбрать отдельный фон клуба через прежние настройки. Следующий выбор
полной темы восстановит её палитру и фон. Остальные настройки чатов сохраняются.

Тема сохраняется в прежнем локальном хранилище `appearance_v1`. На телефоне
это настройки приложения, в веб-версии — хранилище соответствующего браузера
и домена. После очистки данных сайта выбор потребуется сделать снова.

## Совместимость и ресурсы

- Настройки входят в существующий AppearanceController; новая архитектура
  аккаунтов, маршрутов или чатов не вводится.
- Репозитории, SQL, права и существующие обработчики действий не изменяются.
- Реальные фотографии и записи остаются из действующего приложения.
- Превью — отдельные виджеты с подписями-примерами; они ничего не записывают
  в базу и не добавляют чаты.
- Три статичных фона в `assets/themes/` (около 110 КиБ суммарно).
  Шрифты берутся из уже локальных Roboto и PT Serif. Сетевых шрифтов нет.
- Фон отделён от содержимого: при выборе темы меняется оформление,
  а ветки навигации и состояние списка не создаются заново.
- Мягкость изображения встроена в фон. Нет отдельных тяжёлых фильтров blur
  на каждой строке чата. Учитываются reduced motion и высокий контраст.

## Проверка и границы точности

В среде подготовки выполнены запуск проверок сериализации на Dart,
проверка синтаксиса изменённых Dart-файлов и проверки установщика
(резервная копия, повторная установка, конфликт, откат, сохранность настроек).

Полного Flutter SDK в среде подготовки нет. `flutter analyze`, widget-тесты,
реальный рендер на iPhone/Android и измерение FPS здесь НЕ выполнялись.
Их нельзя считать пройденными до запуска на Mac и проверки на устройстве.
Установщик останавливается при ошибке анализатора или тестов.

Буквальное совпадение «1 в 1» не подтверждено: исходные фоны и точные шрифты
макетов не предоставлены отдельно; закрытые интерфейсом участки фона
восстановлены генерацией. Material-иконки сохранены как живые векторные
виджеты и получают стили тем; это не идентичные рисованные иконки макета.
На первом референсе пять пунктов навигации, в Mellon сохранены три текущих.
Во втором референсе нет некоторых рабочих элементов Mellon: «О храме»,
адрес и ближайшее событие сохранены. Тексты, роли, большой системный шрифт
и реальные данные влияют на высоту карточек. Это функциональная реализация
трёх оформлений, а не подтверждённая попиксельная копия референсов.

После запуска проверьте: все три темы, отмену, повторное открытие приложения,
адрес → карта, «О храме», четыре раздела клуба, меню реального чата,
истории/редактирование фото и прокрутку. Для окончательной визуальной доводки
нужны снимки этой версии на устройстве и оригинальные дизайн-ресурсы.

## Сборка или публикация — отдельным явным действием

Собрать папку для ручной загрузки:

```bash
cd ~/Desktop/moy_prihod && python3 ~/Downloads/update_mellon_themes.py --build
```

Загрузить в уже настроенный бакет `mellon2026` (AWS-профиль `mellon`):

```bash
cd ~/Desktop/moy_prihod && python3 ~/Downloads/update_mellon_themes.py --upload
```

Публикация отправляет файлы и вложенные папки, затем главную страницу;
посторонние объекты бакета не удаляются.
Адрес: https://mellon2026.website.yandexcloud.net/

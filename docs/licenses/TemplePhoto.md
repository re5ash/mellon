# Фотография храма Александра Невского

Файл приложения: assets/map/alexander_nevsky.jpg.

Автор: **Zairon**. Дата фотографии: 26 мая 2019 года.

Оригинал: [Kaliningrad Alexander Nevsky 1.jpg — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Kaliningrad_Alexander_Nevsky_1.jpg).

Лицензия: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). [Полный текст лицензии](https://creativecommons.org/licenses/by-sa/4.0/legalcode).

В приложении используется уменьшенная копия 960×567 пикселей. При отображении фотография обрезается по форме карточки или метки с сохранением исходных пропорций.

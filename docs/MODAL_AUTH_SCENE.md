# Регистрация, вход и восстановление в одном окне Mellon

«Войти», «Зарегистрироваться» и «Забыли пароль?» плавно переключают содержимое одного модального окна. Предыдущая форма исчезает за 260 мс, следующая появляется за 380 мс. Размер окна, фон, цвета и шрифты сохраняются. При увеличенном тексте содержимое можно прокручивать.

Восстановление содержит заголовок, пояснение, поле Email с конвертом, кнопку «Отправить ссылку» и «Вернуться ко входу». Email переносится между формами. Данные регистрации и отдельный пароль входа сохраняются при переключении.

Кнопка отправляет настоящее письмо через существующий механизм восстановления. До её нажатия запрос не выполняется. После отправки в этом же окне появляется сообщение с адресом, на который запрошено письмо. Ошибки показываются здесь же, поле остаётся доступным для исправления. Повторная отправка доступна через 60 секунд; переключение форм не сбрасывает ожидание. Многократное нажатие во время запроса не создаёт параллельных отправок. Сама ссылка из письма использует прежний процесс подтверждения и установки пароля.

Солнце и птицы убраны. Остались исходное изображение храма и деревьев и движущиеся облака. Скорость облаков уменьшена примерно на 30%: цикл увеличен с 32 до 45,714 секунды. Облака проходят через фон и возвращаются в начало только за пределами видимой области. Переключение форм не пересоздаёт фон и не запускает анимацию заново.

При системном отключении анимации фон неподвижен, формы переключаются сразу.

## Установка

Замените прежний `update_mellon_modal_auth_scene.py` в «Загрузках» новой версией. Если приложение запущено через `flutter run`, нажмите `q` в его терминале. Затем выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_modal_auth_scene.py
flutter analyze
flutter test
```

Установщик создаёт резервную копию изменяемых файлов рядом с проектом, в `moy_prihod_update_backups`. Повторный запуск безопасен. Неизвестные локальные изменения он не перезаписывает. Изменений SQL и зависимостей нет.

После успешной проверки:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

## Проверка в приложении

1. В режиме гостя откройте «Молодёжный клуб», заполните несколько полей регистрации и нажмите «Войти».
2. Введите email и нажмите «Забыли пароль?». В том же окне должна появиться форма восстановления с введённым адресом.
3. Нажмите «Отправить ссылку». Проверьте сообщение в окне, отсчёт повторной отправки и письмо во входящих или «Спаме».
4. Вернитесь ко входу, затем к восстановлению: адрес сохраняется, ожидание не начинается заново.
5. Вернитесь к регистрации: её данные сохраняются. При всех переключениях окно остаётся прежнего размера, облака продолжают путь без скачка.
6. Проверьте исправление ошибочного email и неверного пароля без обновления страницы.

## Проверки при подготовке

Проверяются синтаксис и форматирование Dart, сохранность прежних исправлений авторизации, исходного изображения и SQL. Установщик проверяется на поддерживаемой предыдущей версии: установка, точная резервная копия, сохранение конфигурации и повторный запуск.

Flutter-тесты покрывают переходы между тремя формами, сохранение размеров и данных, непрерывную анимацию, отправку и повторные нажатия, отсчёт, редактирование после ошибки и прокрутку с крупным текстом. В среде подготовки нет Flutter SDK: `flutter analyze` и `flutter test` здесь не запускались. Выполните их на Mac перед запуском приложения.

# Mellon — плавающая нижняя навигация

Панель оформлена единой капсулой с боковыми отступами, тонкой границей и мягкой тенью. Активная плашка остаётся одним элементом: за 320 мс её передний край движется быстрее заднего, затем плашка возвращается к ширине выбранного пункта. При быстром повторном выборе движение продолжается из текущего положения.

Подписи «Лента», «Молодёжный клуб», «Карта», иконки и обработчики переходов сохранены. При открытии гостевого окна регистрации или статуса заявки выбранный раздел под модальным окном остаётся прежним. Роли и доступы не меняются. Боковая навигация широкого экрана не меняется.

Цвета иконок и подписей меняются вместе с плашкой. Лёгкое уменьшение до 0.97 применяется только к содержимому нажатого пункта. Размеры панели и позиции остальных элементов не зависят от выбора. Высота рассчитывается по самым высоким подписям с учётом системного размера текста. Сохранены нижняя безопасная область, клавиатурный фокус и семантика кнопок. При уменьшении движения анимации отключены.

## Установка

Остановите Flutter клавишей `q` в его терминале. Скачайте `update_mellon_floating_navigation.py` в «Загрузки» и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_floating_navigation.py
flutter analyze
flutter test
```

Установщик изменяет только компонент нижней панели, добавляет его тесты и эту инструкцию. Создаётся резервная копия. Неизвестные локальные изменения компонента останавливают установку до записи. SQL, зависимости, экраны и маршрутизация не меняются.

Отдельные проверки:

```bash
flutter test test/floating_navigation_test.dart test/design_navigation_test.dart test/guest_review_test.dart --reporter expanded
```

Проверены синтаксис Dart, импорты, геометрическая модель анимации и установщик. Flutter SDK в среде подготовки отсутствует: `flutter analyze`, widget-тесты и запуск на Web/PWA/Android здесь не выполнялись. Тесты проверяют растяжение, быстрый повторный выбор, изменение раздела извне, отсутствие ложного переключения при модальном окне, увеличенный текст и режим уменьшения движения.

## Запуск и обновление сайта

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Для Netlify после успешных проверок заново соберите и опубликуйте `build/web`:

```bash
flutter build web --release --dart-define-from-file=config/development.json
open build/web
```

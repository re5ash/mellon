# Mellon — эмодзи и переключение чатов

Обновление подготовлено по записи экрана от 13 сентября 2026 года.

В списке клубных чатов удалены кнопка поиска и скрытое поле поиска. Список показывает все доступные пользователю чаты.

Рядом с полем сообщения появилась кнопка «Эмодзи». Она открывает компактную панель поверх переписки: категории, поиск по русским названиям и сетка символов. Нажатие вставляет эмодзи на место курсора или выделенного текста. Можно выбрать несколько эмодзи подряд и отправить обычной кнопкой со стрелкой. Панель не изменяет высоту переписки. В чатах без права отправки кнопка недоступна вместе с полем ввода.

Включён полный набор Unicode Emoji 17.0: 3 953 уникальные последовательности, включая fully-qualified emoji и компоненты, в десяти категориях. Включены оттенки кожи, составные эмодзи и флаги. Используется цветной шрифт Noto Color Emoji; он поставляется вместе с обновлением. Все 3 953 последовательности проверены HarfBuzz: каждый вариант формируется одним непустым глифом. Это проверка покрытия шрифта; отрисовку выполняет Flutter на устройстве.

На присланном видео при выборе комнаты сначала исчезали фон и поле ввода, затем появлялись загрузчик, информация о комнате, права и сообщения. Теперь перед заменой открытой переписки подготавливаются данные следующей комнаты. Текущая остаётся на месте; небольшой индикатор находится в заголовке списка и не изменяет его высоту. После готовности следующая комната показывается в том же блоке. При быстрых нажатиях учитывается последний выбор; запоздалый ответ предыдущего запроса не переключает пользователя обратно. При ошибке загрузки текущая переписка и её черновик остаются открытыми.

Данные подготовленной комнаты удерживаются до первого кадра её отображения, затем временные подписки освобождаются. Проверки полномочий и существующая серверная отправка сообщений сохраняются. Постоянный кеш чужих сообщений не добавляется. Обновление не сохраняет черновики при успешном уходе в другую комнату: это отдельная функция.

Установка на Mac:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_chat_emoji.py
flutter pub get
flutter analyze
flutter test
```

Установщик проверяет известные версии затрагиваемых файлов и создаёт резервную копию. Он включает исправления импорта OverflowBoxFit и лишнего импорта scheduler, а также исправление неиспользуемого key в тесте из предыдущего обновления. Уже установленные изменения пропускаются. Неизвестные изменения останавливают установку до записи. Настройки подключения не входят в обновление. Новых SQL-миграций нет.

Локальный запуск после проверок:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Для обновления существующей веб-версии после успешной проверки:

```bash
flutter build web --release --dart-define-from-file=config/development.json --dart-define=AUTH_REDIRECT_URL=https://eloquent-entremet-040562.netlify.app/
open -R build/web
```

Затем загрузите заново собранную папку build/web в Deploys существующего проекта Netlify. Локальная установка сама опубликованный сайт не изменяет.

Проверка на устройстве: несколько раз переключите комнаты; проверьте отсутствие пустого экрана, сохранение размеров блока и свайп назад. Откройте панель эмодзи, выберите несколько символов, вставьте их в середину текста и отправьте. Проверьте категории, поиск, узкий экран и увеличенный шрифт.

При подготовке использованы Flutter 3.47.2 и Dart 3.13.2. Анализатор завершился без замечаний; все 228 Flutter-тестов прошли. Новые проверки охватывают вставку составных эмодзи, выделение текста, отправку сообщения, недоступность отправки без прав, узкий экран, предварительную загрузку комнаты, запоздалые ответы и ошибку переключения. Старые проверки поиска адаптированы к его удалению; проверки фонового обновления прав и сохранения прокрутки сохранены.

Веб-сборка release успешно создана с примером конфигурации. Панель эмодзи дополнительно отрисована Flutter с настоящим цветным шрифтом и визуально проверена. Рабочая база Supabase и опубликованный сайт при подготовке не изменялись. Сборка по-прежнему выводит ранее существовавшее предупреждение о CupertinoIcons; оно не остановило сборку. Реальные сетевые задержки и плавность на вашем устройстве остаётся проверить после установки.

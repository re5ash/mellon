# Mellon: редактирование пароля в окне регистрации

Исправлены пути, на которых ввод не восстанавливался после нажатия «Продолжить»: пустой или ещё загружающийся список клубов, ошибка его загрузки, незаполненные поля, короткий пароль и отсутствие выбранного клуба. Ошибка сервера использует то же восстановление. Введённые значения и положение курсора сохраняются.

Кнопка «Продолжить» включена в область текстового ввода, поэтому нажатия мышью, включая повторные нажатия во время отправки, не должны снимать фокус с поля. Enter в последнем поле запускает проверку без предварительного завершения редактирования. Сообщения об ошибках полей сохраняются при восстановлении.

## Установка

Скачайте `fix_mellon_registration_input.py` в «Загрузки». В терминале запущенного приложения сначала нажмите `q`. Затем:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_registration_input.py
flutter analyze
flutter test
```

После успешной проверки запустите заново:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Установщик создаёт резервную копию рядом с проектом, проверяет версии файлов и не перезаписывает неизвестные правки. Повторный запуск безопасен. SQL, настройки Supabase, пароли пользователей и исправленный экран входа не изменяются.

## Проверка на вашем Mac

В окне регистрации введите один символ в пароль, несколько раз нажмите «Продолжить», затем удалите символ и введите новый текст. Повторите в подтверждении пароля и с клавишей Enter. Если клубов нет, форма должна объяснять это и позволять редактировать поля; заявка в таком случае не отправляется.

Если зависание возникнет ещё до нажатия «Продолжить» или Enter, сообщите об этом отдельно и укажите, это окно регистрации или экран «Вход». Пароль присылать не нужно.

## Проверка обновления

Синтаксис Dart проверен парсером, файлы отформатированы. Установщик проверен на установку, повторный запуск, сохранение конфигурации, конфликты и откат при прерывании. Добавлены Flutter widget-тесты восстановления подключения и редактирования через него, сохранения выделения, повторных нажатий и Enter. Flutter SDK в среде подготовки отсутствует: `flutter analyze`, `flutter test` и проверка в реальном Chrome здесь не запускались.

Использованы стандартные механизмы Flutter: [TextFieldTapRegion](https://api.flutter.dev/flutter/widgets/TextFieldTapRegion-class.html) и [onEditingComplete](https://api.flutter.dev/flutter/widgets/EditableText/onEditingComplete.html). Протокольные widget-тесты моделируют исчезновение подключения к вводу, но не заменяют проверку автозаполнения Chrome на вашем компьютере.

# Mellon — убрать кружок при переключении чатов

Исправление для версии с установленным fix_mellon_instant_chat_switch.py.

При загрузке сведений о комнате и первых сообщений круговой индикатор больше не отображается. На месте остаётся фон выбранного чата. Название и поле ввода отображаются сразу, как в предыдущем исправлении. Сообщения появляются после ответа сервера; текст «Сообщений пока нет.» выводится только для действительно пустой переписки. До подтверждения прав отправка остаётся недоступной. Ошибки подключения и кнопка повторной попытки сохраняются.

Скачайте fix_mellon_chat_loading_circle.py в Downloads и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_chat_loading_circle.py && flutter analyze && flutter test
```

Затем перезапустите приложение:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Установщик проверяет все изменяемые файлы перед записью, создаёт резервную копию рядом с проектом и не перезаписывает неизвестные локальные изменения. Повторный запуск безопасен. Для опубликованной версии потребуется повторная веб-сборка и загрузка build/web в существующий проект Netlify.

Изменено только представление загрузки. Время получения сообщений зависит от сети. Конфигурация подключения, сервер и набор эмодзи не изменяются.

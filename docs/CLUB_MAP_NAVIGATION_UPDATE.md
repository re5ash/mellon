# Адрес клуба, переход к храму и анимации навигации

1. В Supabase → SQL Editor выполните файл `club_temple_map_coordinates.sql`.
   Он также установлен в `supabase/updates/club_temple_map_coordinates.sql`.
   Запрос заполняет только пустую пару координат существующего храма по ID.
   Адрес, название и уже заполненные координаты не меняются.
2. Скачайте `update_mellon_club_map_navigation.py` в «Загрузки».
3. Остановите предыдущий локальный сервер через Ctrl+C и выполните:

```sh
cd ~/Desktop/moy_prihod && python3 ~/Downloads/update_mellon_club_map_navigation.py
```

Установщик создаст резервную копию изменяемых файлов, выполнит `flutter analyze`,
проверит сценарии карты и навигации и автоматически откроет локальную release-версию.
Терминал должен оставаться открытым. Для остановки используйте Ctrl+C.

## Что изменено

Адрес берётся из `parishes.address`. Связь — существующее поле `parish_id` клуба.
Карта читает те же записи и использует их координаты. Старый отдельный маркер
заменён отображением записи этого храма, дублирующая метка не создаётся.
Нажатие на иконку или текст адреса открывает `/map` с ID храма, плавно приближает
карту до масштаба 17, выделяет метку и сразу открывает её карточку.
Координаты и адрес не передаются в ссылке и не ищутся по названию.

Адрес обновляется по Realtime при его наличии; дополнительно данные перечитываются
раз в 30 секунд и при возвращении на карту. Во время обновления сохраняются последние
полученные данные. Адрес из ответа клуба — временный показ той же записи прихода,
а не отдельное редактируемое поле. Для отсутствующих координат показана понятная ошибка.

Сохранены текущая геометрия карточки клуба, аватар с историями, «О храме», управление
клубом, чаты и события. Нижняя капсула продолжает двигаться между разделами. Иконки:
лента — прокрутка 900 мс, храм — подъём на 2,5 и увеличение до 110% за 460 мс,
карта — оборот за 700 мс. Переключение не ожидает окончания анимации.
Повторное нажатие после завершения повторяет эффект; быстрые нажатия во время эффекта
не создают очередь анимаций. При системном уменьшении движения иконки неподвижны.

## Проверка

В обновление включены Flutter widget tests: выбор по ID при одинаковых названиях,
кликабельность иконки и текста, координаты/масштаб/карточка, обновление адреса,
отсутствие позднего открытия после ухода с карты, непрерывная капсула, мгновенный
callback переключения, повтор иконок и уменьшение движения.
В этой среде Flutter SDK недоступен; анализатор и реальные Flutter-тесты автоматически
запускаются установщиком на Mac до открытия приложения. Проверка установщика выполняется
отдельно: точечная установка, резервная копия, повторный запуск, остановка на неизвестных
изменениях и откат при ошибке записи.

Настройки Supabase/Яндекс, веб-заставка и кэш старта не меняются. Локальная подготовка
использует уже установленный `tools/build_mellon_fast_web.py` с отключённой правкой
Netlify-заголовков. Публикация сайта не выполняется.

Технические справки: https://api.flutter.dev/flutter/animation/AnimationController-class.html
и https://api.flutter.dev/flutter/widgets/MediaQuery/disableAnimationsOf.html.

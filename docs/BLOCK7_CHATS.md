# Блок 7 — чаты Mellon

Установщик обновляет исходники, создаёт резервную копию, запускает Flutter Analyze и тесты, затем открывает локальное приложение. Настройки Supabase, ключи карты, быстрый запуск и публикация Netlify остаются под управлением владельца проекта.

## Порядок установки

1. Сохранить `club_chat_interactions.sql` и `update_mellon_block7.py` в «Загрузки».
2. Открыть Supabase → SQL Editor → New query. Вставить **весь** `club_chat_interactions.sql` и нажать **Run**. Повторное выполнение допустимо. Скрипт не удаляет историю сообщений. Он сохраняет существующие добавления карты, ленты и расписания.
3. В терминале:

```bash
cd ~/Desktop/moy_prihod && python3 ~/Downloads/update_mellon_block7.py
```

4. Дождаться открытия Chrome. Терминал оставить открытым. `Ctrl+C` останавливает локальный сервер.

SQL также находится в проекте: `supabase/updates/club_chat_interactions.sql`. Копия миграции: `supabase/migrations/202609200031_club_chat_interactions.sql`. Выполнять обе копии не нужно.

Если установщик обнаружит неизвестные версии исходников, он перечислит их и остановится **до записи**. Проверки не отключаются. Для отката исходники сохранены в соседней папке `moy_prihod_update_backups`.

## Реализовано

- Свои сообщения справа, входящие слева, время и разделители дней. Настройка вида блоков сохранена.
- Реакции из существующего набора 3953 emoji: счётчик, отметка своей реакции, повторный тап снимает её. Изменения приходят через Supabase Realtime; периодическая проверка доступа также обновляет состояние после временного разрыва соединения.
- Ответ через удержание сообщения или правую кнопку мыши. Автор и фрагмент видны над ответом. Нажатие открывает нужный участок истории и ненадолго выделяет оригинал. После удаления оригинала фрагмент заменяется обозначением удаления.
- Несколько закрепов. Участники соответствующего клуба могут закреплять и откреплять. Ограничения закрытых чатов и проверка членства сохраняются. Переключение закрепов — стрелкой справа, переход к сообщению — нажатием на блок.
- Круглая кнопка вниз появляется при чтении истории. На ней считается количество новых входящих сообщений; собственные сообщения не увеличивают этот счётчик.
- В меню администратора клуба и суперадминистратора: отдельное переименование, смена иконки, удаление с подтверждением. Проверка прав выполняется на сервере, в том числе для старых API редактирования. Существующее право создания чатов сохранено.
- 85 цветных иконок: по 5 вариантов в 17 тематиках. Один канонический ключ хранит выбранную форму, цвет и стиль; список, шапка и превью используют один компонент. Автовыбор учитывает сначала название, затем описание.
- Короткая анимация только при выборе, открытии или новых непрочитанных; одновременно не запускается у всех значков. Системное уменьшение движения учитывается.
- «Оформление → Фон чата»: 24 новых локальных векторных фона — храмы, купола, православные кресты, свечи, орнаменты, абстрактные узоры. У каждой темы по два светлых и два тёмных варианта; шесть прежних фонов сохранены. Настройка записывается только после «Применить». Она локальна для устройства/браузера.

## Плавность и совместимость

Последние сообщения остаются ленивым списком со стабильными ключами. Фоны вынесены в отдельную область перерисовки; в них нет blur, загрузки картинок или постоянной анимации. Чтение старых сообщений сохраняет видимую позицию при обновлении списка. Обновления реакций объединяются, одновременные повторные запросы не создаются. Меню сообщения использует уже загруженные возможности; сервер повторно проверяет права перед каждой записью.

История загружается прежними порциями по 50 сообщений с устойчивым курсором. Переход к далёкому ответу/закрепу загружает небольшой участок вокруг оригинала, затем доступны прежние кнопки истории и возврат вниз. Существующий кэш фотографий Блока 8 сохранён. Это обновление не добавляет отсутствующую в исходном чате загрузку видео и фото; отображение ответов и реакций работает для текущих текстовых сообщений и emoji.

Проверены синтаксис изменённых Dart-файлов и установка/резервирование/откат Python-пакета.

Тесты используют размеры мобильного экрана, уменьшение движения, отмену и применение настроек, действия чата и права управления.

После открытия проверьте на двух аккаунтах: реакция и закреп синхронно появляются у другого участника; новый ответ открывает оригинал; при прокрутке вверх виден счётчик; переименование/иконка доступны администратору; удаление требует подтверждения. Для оценки 60/120 FPS нужен замер на целевом телефоне в release/profile-режиме.

# Mellon — экран молодёжного клуба

Экран повторяет композицию присланного макета: фото храма и сведения о клубе, ближайшее событие, вкладки «Чаты», «Расписание», «События», «Помощь», нумерованный список чатов с цветными иконками. Название продукта — Mellon. Нижняя навигация остаётся прежней.

## Установка

Обновление рассчитано на текущую версию с выбором клубов и единым окном входа (`CLUB_NAVIGATION_UPDATE.md`, SQL 018).

1. Остановите запущенный Flutter клавишей `q` в его терминале. Скачайте `update_mellon_club_dashboard.py` в «Загрузки».
2. Выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_club_dashboard.py
flutter pub get
flutter analyze
flutter test
```

Установщик проверяет исходные файлы до записи, сохраняет резервную копию в соседнюю папку `moy_prihod_update_backups`. Неизвестные изменения в затрагиваемых файлах останавливают установку. Повторный запуск не устанавливает обновление второй раз. Конфигурация подключения, исправления ввода пароля, фон регистрации и нижняя навигация сохраняются.

3. Откройте Supabase → SQL Editor → новый запрос. Вставьте **весь** файл `mellon_club_dashboard.sql` и нажмите Run. Выполняется один раз; повторный запуск этого же файла безопасен. Если SQL сообщает об отсутствии обновления 018, сначала примените ранее выданный `mellon_club_navigation.sql`, затем этот файл. Старые миграции заново выполнять не нужно.
4. Запустите приложение:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Изменения в локальном проекте не публикуют сайт автоматически. Для ссылки Netlify после проверки заново подготовьте веб-сборку вашим существующим скриптом публикации и загрузите обновлённую папку `build/web` в тот же проект Netlify.

## Работа экрана

- После входа сохраняется выбор клуба. Для уже вошедшего участника с одним доступным клубом кнопка нижней навигации сразу открывает его экран. Если доступно несколько клубов, сначала показывается выбор.
- Иконка закладки в верхней карточке открывает выбор другого клуба. «О клубе» показывает описание. Круглая стрелка обновляет данные.
- При установке в существующих клубах создаются отсутствующие 13 чатов из макета. Новые клубы получают тот же начальный набор. Существующие одноимённые чаты, их настройки, сообщения и закрытый «Актив» сохраняются.
- Руководитель, администратор соответствующего клуба и суперадмин могут добавлять, переименовывать и удалять чаты в пределах своих прав. Для добавления — «+» у заголовка. Для изменения — многоточие или долгое нажатие на строку.
- При удалении требуется подтверждение. Чат исчезает, открытие старой ссылки и доступ к сообщениям закрываются сервером. Данные помечаются удалёнными, а не стираются физически. Повторная установка не возвращает удалённый чат.
- Название, описание, иконка и тип чата сохраняются в существующей записи. Неподтверждённые сервером изменения не выдаются за сохранённые; при конфликте редактирования нужно обновить клуб и открыть настройки чата заново.
- Участник не получает кнопок управления. Модератор сохраняет свои существующие права модерации сообщений; создание чатов проверяется отдельным существующим разрешением.
- Вкладки используют существующие события и просьбы о помощи выбранного клуба. Для привязки существующей просьбы к клубу предусмотрен `help_requests.youth_id`. Новые типы сущностей и роли не создаются. Данные других клубов не подмешиваются.
- Ближайшее событие, время сообщения и количество непрочитанных вычисляются из настоящих записей. При отсутствии данных показывается спокойное пустое состояние. Отметки прочтения хранятся отдельно для аккаунтов на текущем устройстве и пока не синхронизируются между устройствами.
- Фото храма используется из присланного макета как общая иллюстрация. Это не утверждение, что на нём изображён храм каждого клуба. Имя клуба, адрес и руководители берутся из базы. Фото не содержит встроенных кнопок: интерфейс реализован виджетами.
- Текст переносится, высота карточек зависит от содержимого. На узком экране или при увеличенном шрифте элементы перестраиваются, а не обрезаются. Тёмное оформление и системное масштабирование учитываются.

## Проверка

В среде подготовки прошли 14 проверок SQL нового экрана и 12 проверок прежней логики клубов с установленным обновлением: права, независимость клубов, повторные запросы, конфликт версий, удаление, сохранность сообщений, закрытый «Актив», ограниченный гость, реальные непрочитанные, события и помощь.

Dart-файлы прошли форматирование и синтаксический разбор, проверены пути импортов. Flutter SDK в этой среде отсутствует: `flutter analyze`, `flutter test` и визуальное сравнение работающего Flutter-экрана здесь не запускались. Добавлены виджет-тесты для переключения вкладок, поиска, создания/переименования/удаления, отказа сервера, выбора клуба и увеличенного шрифта. Выполните команды выше на Mac; это обязательная проверка перед публикацией.

Проверьте в Chrome и на телефоне: открытие клуба, 4 вкладки, переход в чат, добавление/переименование/удаление администратором, отсутствие управления у участника, возврат к выбору другого клуба, прежние вход и восстановление пароля.

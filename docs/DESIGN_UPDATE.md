# Дизайн и навигация: первый этап

Обновление для установленной версии с профилем и миграциями 1–8. На Mac до этого обновления подтверждены `flutter analyze` без замечаний, 37 успешных тестов, сохранение профиля после перезагрузки и применение миграции 8.

## Что меняется

- Три главных раздела: **Лента / Mellon / Карта**. На широком экране — боковая навигация, на узком и в невысоком окне — нижняя.
- В ленте четыре вкладки: Общая, Mellon, События, Помощь. Работают нажатия, горизонтальные свайпы и ссылки `/feed?tab=events`. При крупном тексте вкладки прокручиваются горизонтально.
- «Mellon» открывает домашнюю страницу активного участника: название и адрес из базы, быстрые переходы к новостям, чатам, событиям и расписанию, ближайшее событие, доступные чаты и свежие публикации.
- Для заявки на рассмотрении — отдельный экран с настоящим названием прихода, статусом, проверкой обновления и переходами в общую ленту/карту/настройки.
- Значок аккаунта справа сверху открывает профиль, оформление и каталог приходов. «Управление» появляется по разрешениям сервера. В профиле остаётся выход из аккаунта.
- У администратора с соответствующими правами на странице прихода есть кнопка «Управлять приходом». Существующие формы создания/редактирования и рассмотрения заявок продолжают использовать прежние серверные RPC.
- Цвета, типографика и карточки централизованы. Заголовки используют встроенный PT Serif с кириллицей; лицензия OFL включена. Светлая, тёмная и системная темы сохраняются.
- «Подробнее» в карточках раскрывает текст на месте, повторное нажатие сворачивает его.

Это первый этап переноса присланных макетов. Фотографии, логотип с куполами и декоративные фоны, новый вид регистрации и каталога будут отдельным этапом. Здесь используются нейтральные иконки: демонстрационные фотографии и вымышленные участники/чаты не добавляются в базу.

Раздел «Расписание» пока показывает опубликованные предстоящие события прихода с датой и временем. Отдельного редактора повторяющихся богослужений нет. Карта остаётся существующей заготовкой, поиск по всей ленте и загрузка фотографий не добавлены.

## Установка

1. Скачайте `update_moy_prihod_design.py`.
2. В **терминале VS Code**, открытом в папке `moy_prihod`, остановите запущенный Flutter клавишей `q`. Дождитесь приглашения `moy_prihod %`.
3. Напечатайте `python3` и пробел, перетащите скачанный файл из Finder в терминал и нажмите Enter. Так используется точное имя файла, даже если браузер добавил `(1)`.
4. После сообщения об установленном обновлении выполните по очереди:

```bash
flutter pub get
flutter analyze
flutter test
```

5. Если проверки прошли, запустите приложение:

```bash
flutter run -d chrome --web-port=8080 --dart-define-from-file=config/development.json
```

**Команды Supabase для этого обновления не требуются.** Все восемь миграций сохраняются без изменений. Личные данные, конфигурация подключения, Android runner, локальные правила анализатора и файл зависимостей `pubspec.lock` не заменяются. В `pubspec.yaml` добавляется только подключение встроенных шрифтов.

Установщик проверяет совместимость до записи, создаёт резервную копию изменяемых файлов рядом с проектом и восстанавливает исходники при ошибке записи. Повторный запуск уже установленного обновления ничего не меняет. При неизвестных изменениях исходников он остановится — пришлите его вывод.

## Проверка в Chrome

1. В общей ленте переключите четыре вкладки нажатием и свайпом. Перезагрузите страницу на «Событиях»: вкладка должна сохраниться.
2. Войдите обычным участником: «Mellon» должен показывать его приход. Откройте «Чаты» и вернитесь стрелкой назад.
3. Войдите супер-администратором: меню аккаунта → «Управление» → приход. Проверьте создание публикации и переходы к заявкам/редактированию.
4. В инкогнито проверьте, что меню не показывает управление, а вкладка «Mellon» в ленте предлагает войти. Приватных записей быть не должно.
5. Проверьте ожидающую заявку отдельным обычным аккаунтом: приватная лента и чаты до одобрения не открываются.
6. Уменьшите окно, увеличьте масштаб текста, переключите светлую/тёмную тему. Для окончательной проверки Safari/PWA нужен запуск на настоящем iPhone через HTTPS.

## Проверки подготовки

Проверены синтаксис Dart и относительные импорты; добавлены тесты маршрутов, вкладок, ограничений гостя/ожидающего участника, административного меню, адаптивности и фильтра событий своего прихода. Отдельно проверяется установщик: конфликты, повторный запуск, резервная копия и восстановление при ошибке.

Flutter SDK в среде подготовки отсутствует: **новые `flutter analyze` и `flutter test` ещё не выполнены**. Их результат нужно получить на вашем Mac; прежние 37 успешных тестов относятся к версии до этого обновления. Серверные миграции не менялись, поэтому предыдущие SQL-проверки не выданы за новую проверку интерфейса.

Шрифт: официальный репозиторий Google Fonts, `ofl/ptserif`; исходные файлы `PT_Serif-Web-Regular.ttf`, `PT_Serif-Web-Bold.ttf`, `OFL.txt`.

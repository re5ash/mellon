# Mellon — Яндекс Карта без маршрутизации

Это обновление устанавливается после `update_mellon_map.py`. Исправление `fix_mellon_map_403.py` может быть уже установлено; установщик принимает обе версии веб-шаблона. SQL повторно выполнять не требуется.

## Подключение

1. Откройте [Кабинет разработчика Яндекса](https://developer.tech.yandex.ru/), войдите со своим Яндекс ID.
2. Нажмите «Подключить API» и выберите **Tiles API**. Нужен именно этот сервис, не JavaScript API, Геокодер или Получение деталей маршрута. Подключите бесплатную версию при соблюдении её условий.
3. Скопируйте выданный ключ. В ограничениях ключа укажите домены `localhost` и `eloquent-entremet-040562.netlify.app` — по одному в строке, без протокола и порта. Если адрес опубликованного приложения поменялся, укажите действующий адрес. Активация ключа и ограничений может занять до 15 минут.
4. Скачайте установщик в Downloads и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_yandex_map.py
python3 tools/configure_yandex_map.py
```

Последняя команда предложит вставить ключ в терминал. Она добавит только `YANDEX_TILES_API_KEY` в существующий `config/development.json`, сохранив настройки Supabase и входа. Перед записью создаётся резервная копия. Ключ не нужно отправлять в чат.

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Перед повторным запуском остановите старый `flutter run` клавишей q. Горячая перезагрузка не меняет параметры сборки.

Для Netlify заново соберите и загрузите build/web:

```bash
flutter build web --release --dart-define-from-file=config/development.json --dart-define=AUTH_REDIRECT_URL=https://eloquent-entremet-040562.netlify.app/
open build
```

Локальное обновление не меняет опубликованный сайт. Если используете другой JSON при сборке, добавьте в него этот же параметр.

## Поведение

- В основном разделе и при выборе точки события используется официальная подложка Яндекс Карт с русскими подписями и обновлённым оформлением `future_map`.
- Явно задана сферическая проекция `web_mercator`, совместимая с FlutterMap. Это предотвращает смещение метки относительно здания.
- Метка с фотографией, плавная карточка, график работы, «Поделиться», расстояние по прямой и плашки событий работают внутри Mellon.
- Кнопка «Проложить маршрут» удалена. Приложение не обращается к сервисам маршрутизации.
- Компактная плашка высотой 40 пикселей содержит логотип Яндекса и значок информации. Обязательная ссылка на главную страницу Яндекс Карт находится на самом логотипе; отдельная надпись «Открыть в Картах» убрана. Пропорции и встроенные отступы официального изображения сохранены. Нажатие не строит маршрут.
- Картинка карты сама по себе не запрашивает геолокацию. Местоположение определяется только по нажатию соответствующей кнопки.
- Пока ключ не настроен, показано понятное сообщение без запросов к сервису и без меток на пустой подложке.
- Встроенное долговременное сохранение тайлов отключено. Браузер использует обычный HTTP-кэш по заголовкам сервера. Предварительное скачивание областей не выполняется.
- Запросы от карты и редактора точки распределяются во времени — не чаще 20 в секунду на запущенный экземпляр приложения. Это не отменяет общий лимит ключа при одновременной работе многих пользователей.

## Стоимость и ограничения

[Tiles API](https://yandex.ru/maps-api/products/tiles-api) указан Яндексом как бесплатный для коммерческого и некоммерческого использования при соблюдении условий, с ограничением 30 запросов в секунду. Сама установка не оформляет платную подписку. Условия проверены 14 сентября 2026 года; действующие ограничения смотрите в кабинете Яндекса.

Ограничение по домену рассчитано на веб/PWA. Для будущих нативных сборок нужно отдельно настроить разрешённую идентификацию запросов у Яндекса и проверить её на устройстве. Нельзя просто отключать ограничения опубликованного ключа.

## Проверка

Проверки включают отсутствие построения маршрутов, сохранение положения карты при карточке, выбор точки события, события на сегодня, отказ в геолокации, маленькие экраны, отсутствие запросов без ключа и корректную проекцию.

Для проверки реальной подложки необходим ваш активный ключ: в этом обновлении чужие или демонстрационные ключи не используются. Если карта не загрузилась, проверьте выбранный продукт Tiles API, активацию ключа, ограничения доменов и повторную сборку после ввода ключа.

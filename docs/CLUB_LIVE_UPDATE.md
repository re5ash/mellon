# Mellon — обновление молодёжного клуба

Обновление рассчитано на рабочую версию после исправления фонового обновления (171 пройденный тест у пользователя), а также на уже установленную первую версию `update_mellon_club_live.py`. Оно сохраняет нижнюю навигацию, окно авторизации, оформление и существующие роли.

## Установка

1. Остановите запущенное приложение клавишей `q` в терминале с `flutter run`.
2. Скачайте `update_mellon_club_live.py` в «Загрузки». Выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_club_live.py
flutter analyze
flutter test --reporter expanded
```

Установщик сверяет исходные файлы, создаёт резервную копию рядом с проектом и заменяет только файлы этого обновления. Неизвестные изменения он не перезаписывает. Повторный запуск безопасен. Новых зависимостей нет.

3. Если `mellon_club_live.sql` ещё не установлен: в Supabase → SQL Editor откройте новый запрос, вставьте **весь** файл и нажмите Run. Он также находится в проекте: `supabase/updates/club_live.sql`. Сначала должно быть установлено предыдущее обновление `mellon_club_dashboard.sql` (019). SQL выполняется одной транзакцией; повторный запуск того же файла безопасен. **Если этот SQL уже успешно выполнен, повторять его не нужно: в продолжении обновления база не менялась.**
4. После успешных проверок и SQL запустите:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

## Что изменено

- Карточка выбранного клуба открывается сразу. Выбор сохраняется на устройстве отдельно для каждого аккаунта и восстанавливается после перезапуска. Удалены выбор другого клуба из шапки и ручное обновление. Вместо «О клубе» — «О храме». Если клубов несколько и ещё ни один не выбран, остаётся список для первоначального выбора.
- До одобрения видна только базовая карточка с кнопкой «Подать заявку» внутри неё. Ожидание решения хранится в базе; повторная кнопка не показывается. При отклонении серверный статус заменяет локальное ожидание. После одобрения внутренние разделы появляются автоматически.
- В настройках клуба есть «Покинуть клуб» с подтверждением «Вы точно хотите выйти?». Выход снимает членство, клубные роли и доступ к чатам только в выбранном клубе. Можно подать новую заявку. Глобальные полномочия суперадмина сохраняются и продолжают давать административный доступ ко всем клубам.
- В списке чатов отображаются последнее сообщение, автор, время и личный счётчик непрочитанных. Превью сообщения занимает до двух строк; полный текст доступен в переписке.
- На широком экране список и переписка находятся рядом, со своими прокрутками. На узком экране переписка занимает область чатов, а стрелка возвращает к списку. Маршрут страницы и нижняя навигация не меняются.
- Обновления поступают через Supabase Realtime. Новые сообщения и отметки о прочтении обновляют список, не пересоздавая данные открытого чата. После восстановления подключения или возврата к приложению история и права запрашиваются заново без перезагрузки страницы.
- После успешного выхода внутренние разделы скрываются сразу, даже если обновление списка клубов задержалось. Неудачный выход не меняет членство. Зависшая отметка о прочтении ограничена таймаутом и не блокирует следующие отметки; недоступное локальное хранилище не мешает работе клуба.
- Прочитанность хранится отдельно для пользователя и чата. Учитываются видимые сообщения активной переписки; курсор не откатывается назад и различает сообщения с одинаковым временем. Свои и удалённые сообщения не увеличивают счётчик. При переходе на серверные счётчики старые локальные отметки не импортируются: начальная граница берётся из существующей записи членства, после чего сохраняется независимо от изменений роли.
- Расписание, события и помощь доступны участникам для чтения. Управлять ими могут существующие администратор клуба, руководитель и суперадмин. Модератор не получает управление этими разделами. Расписание использует существующую таблицу событий.
- Фото меняют администратор соответствующего клуба и суперадмин. На компьютере карандаш появляется при наведении; на телефоне первое касание фото показывает карандаш, следующее касание карандаша открывает редактор. Участник и руководитель без роли администратора видят обычное фото.
- Редактор поддерживает перемещение, масштаб ползунком/двумя пальцами и предпросмотр. Кадр автоматически приводится к размеру 1240×840 и сохраняется в PNG. Соотношение сторон выбирать не требуется. Поддержка исходных форматов зависит от декодера браузера/системы; если фото не открывается, текущая фотография сохраняется.

## Проверка на двух аккаунтах

1. Участник подаёт заявку. Перезагрузите страницу: статус остаётся, внутренние разделы скрыты. Руководитель одобряет её — разделы открываются.
2. Откройте один чат на двух устройствах. Сообщение первого пользователя появляется у второго автоматически. У второго счётчик сбрасывается после просмотра и остаётся прочитанным после перезапуска.
3. Прокрутите переписку к старым сообщениям, затем отправьте новое с другого устройства: непросмотренное сообщение не должно считаться прочитанным.
4. Проверьте фото на компьютере и телефоне. Отмена не меняет фото, сохранение показывает выбранный кадр. У обычного участника карандаша нет.
5. Выйдите из одного клуба. Его чаты и прямые ссылки недоступны; участие в другом клубе сохраняется.
6. Проверьте создание, изменение и удаление чатов разрешёнными ролями. В расписании, событиях и помощи обычный участник и модератор не видят кнопок управления.

Они содержат проверки прямых запросов, RLS, другого клуба и подмены аккаунта.

- В продолжении добавлены проверки сохранения выбранного клуба по аккаунтам, скрытия переписки при задержке обновления после выхода, восстановления после таймаута отметки и обновления истории при переподключении. Исправлены прежние тесты, ожидавшие удалённый экран выбора клуба и локальную загрузку счётчиков.
- Проверена установка поверх обеих поддерживаемых версий, повторный запуск, сохранение конфигурации, резервная копия и откат при прерывании записи. SQL продолжения совпадает с первой версией обновления.

### Исправление теста выхода из клуба

В присланном пользователем результате после установки обновления прошли 182 теста, один остановился при подготовке данных, до выполнения выхода из клуба. В `test/club_followup_test.dart` исправлено создание карты данных клуба: она явно допускает значения разных типов, включая `is_member: true`. Также убран избыточный оператор `!`, отмеченный анализатором. Проверки скрытия чатов и повторной подачи заявки сохранены; код приложения и SQL этим исправлением не меняются.

Скачайте установщик заново и запустите его. Для проверки этого исправления достаточно:

```bash
flutter analyze
flutter test test/club_followup_test.dart --reporter expanded
```

Повторный запуск исправленного теста в среде подготовки недоступен без Flutter SDK.

### Исправление открытия фотографии в браузере

При выборе фото редактор использовал `ImageDescriptor.width` и `height` для закодированного изображения. В реализации Flutter Web эти свойства выбрасывают `UnsupportedError`, поэтому ошибка возникала до загрузки в Supabase даже для обычного изображения. Декодирование заменено на `instantiateImageCodecWithSize`: размеры получаются через совместимый с браузером обработчик, большая фотография автоматически уменьшается с сохранением пропорций. Кадрирование и предпросмотр продолжают использовать одно изображение.

Скачайте обновлённый `update_mellon_club_live.py`, заменив прежний файл в «Загрузках», и запустите его. SQL для этого исправления не нужен. Затем проверьте:

```bash
flutter analyze
flutter test test/club_photo_test.dart test/club_photo_decode_test.dart --reporter expanded
flutter test --platform chrome test/club_photo_decode_test.dart --reporter expanded
```

Добавлен отдельный тест открытия, уменьшения и экспорта фото, который можно запускать в Chrome: обычные тесты на Mac не воспроизводили ограничение веб-движка. Самостоятельно запустить Flutter-тесты в среде подготовки по-прежнему невозможно без SDK. После установки полностью перезапустите локальное приложение. Для Netlify соберите и опубликуйте новую `build/web`.

Основание исправления: [исходный код Flutter Web, `ImageDescriptor`](https://github.com/flutter/flutter/blob/master/engine/src/flutter/lib/web_ui/lib/painting.dart), [API `instantiateImageCodecWithSize`](https://api.flutter.dev/flutter/dart-ui/instantiateImageCodecWithSize.html).

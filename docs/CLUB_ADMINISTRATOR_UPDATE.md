# Mellon — администратор молодёжного клуба

В разделе «Молодёжный клуб» добавлена роль **«Администратор»**. Название и доступность загружаются из базы в существующее окно. Стиль, радиокнопки, выбор одного значения и одна кнопка «Сохранить изменения» сохраняются.

## Установка

Обновление рассчитано на установленный каталог ролей 016 и исправление, после которого прошли 150 Flutter-тестов.

1. Скачайте `update_mellon_club_administrator.py` в «Загрузки». Если приложение запущено, остановите его клавишей `q` в терминале.
2. Выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_club_administrator.py
flutter analyze
flutter test
```

Установщик проверит версии файлов, создаст резервную копию рядом с проектом и сохранит конфигурацию подключения. Повторный запуск допускается. Сам установщик не подключается к базе.

3. Откройте Supabase → **SQL Editor → New query**. Вставьте **весь** файл `mellon_club_administrator.sql` и нажмите **Run**. Это новое обновление 017: прежние SQL повторять не нужно. В проекте тот же SQL находится в `supabase/updates/club_administrator.sql`.
4. После успешных проверок запустите приложение:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Если используете штатные миграции Supabase CLI, примените `202609120017_club_administrator.sql` вместо SQL Editor. Используйте один способ. Повторное выполнение одного и того же SQL Editor файла безопасно. Если ключ `youth_admin` уже был создан вручную, обновление остановится без замены этой роли: необходимо сверить существующий каталог.

## Как назначить администратора

Под суперадмином откройте **Управление → Роли → нужный человек**. В блоке **Молодёжный клуб** выберите конкретный клуб, затем **Администратор → Сохранить изменения**. В блоке «Всё приложение» эту роль выбирать не нужно: там её нет.

У нового клуба автоматически будет тот же набор клубных ролей. Его администратора назначьте отдельно. Один человек может иметь разные роли в нескольких клубах.

Администратор клуба открывает **Молодёжный клуб → Управление молодёжкой → Роли** для назначения ролей. Для создания чата: **Управление молодёжкой → Чаты → Создать**.

## Права

| Действие | Администратор клуба |
| --- | --- |
| Назначить или снять руководителя, модератора; вернуть обычное участие | В своём клубе |
| Создать и редактировать чаты | В своём клубе |
| Управлять участниками, активом, заявками, событиями и публикациями; модерировать сообщения | В своём клубе, как руководитель |
| Управлять другим клубом | Только при отдельном назначении в нём |
| Менять глобальные права, назначать суперадмина | Нет |
| Назначать или снимать других администраторов клуба | Нет, это делает суперадмин или уже уполномоченный администратор соответствующего прихода |

Существующие руководители и модераторы сохраняют свои роли. Изменение выбранного клуба не сбрасывает другие клубы, глобальный доступ, профиль и статус актива. Обновление само никому не назначает администратора.

Проверки выполняются в базе, а не только через скрытие кнопок. Нельзя обойти иерархию исключением администратора из участников. Истечение назначения, отзыв членства, архив клуба и гостевое ограничение прекращают действие клубных полномочий. Сохранённые назначения гостя остаются в базе и возобновляются после снятия ограничения.

## Проверка

При подготовке выполнены проверки SQL в PGlite: отдельные администраторы разных клубов, повышение и понижение ролей, создание и редактирование чатов, защита от повышения собственных прав, исключения администратора через старый экран, сохранность других назначений и повторная установка SQL. Auth и Storage представлены тестовыми схемами; рабочая база Supabase не изменялась.

Добавлен Flutter-тест выбора администратора и сохранности других блоков. Здесь нет Flutter SDK: `flutter analyze`, `flutter test` и проверку экрана в Chrome нужно выполнить на вашем Mac. После установки проверьте под двумя разными аккаунтами: администратор первого клуба управляет первым, администратор второго — вторым.

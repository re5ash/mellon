# Ускорение первого открытия Mellon — 19.09.2026

До исправления Flutter ждал CanvasKit с www.gstatic.com, Roboto с
fonts.gstatic.com и все шрифты из FontManifest, включая NotoColorEmoji
размером 10 673 480 байт. Даже локальная веб-сборка зависела от внешней сети
до появления первого кадра.

Изменения:

- CanvasKit берётся из каталога `canvaskit/` самой сборки; относительный base
  href учитывается через `document.baseURI`.
- Roboto включён в проект. Файл взят из установленного Flutter SDK:
  `engine/src/flutter/txt/third_party/fonts/Roboto-Regular.ttf`.
  Лицензия Apache 2.0 сохранена в `assets/fonts/Roboto-LICENSE.txt`
  и включена в веб-сборку (источник: googlefonts/roboto, LICENSE).
- MellonEmoji зарегистрирован через FontLoader после первого кадра.
  Эмодзи остаются доступны, загрузка больше не блокирует интерфейс.
  Ошибка загрузки необязательного шрифта не останавливает приложение.

Первый локальный запуск в одном браузере: до 2619 мс, после 432 мс.
Замер сделан по событию `flutter-first-frame`, с отключённым HTTP-кэшем
локальных файлов. Это время первого кадра, не загрузки данных Supabase.
Время публичного сайта зависит также от соединения и хостинга.

Проверки: Flutter analyze без замечаний; 18 тестов запуска, эмодзи и
оформления прошли; релизная сборка успешна. В браузере проверены лента,
события, помощь, Яндекс Карта и карточка храма.

Сборка и публикация выполняются прежней командой:

```bash
python3 tools/mellon_web.py build
```

В Netlify нужно загружать целиком `build/web`, включая `canvaskit/` и
`assets/`. Только локальная сборка не обновляет опубликованный сайт.
Миграции базы и новые ключи не требуются.

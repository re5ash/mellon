# Исчезновение удалённых сообщений

Обновление после исправления ролей и профиля. Поддерживает также повторную установку поверх первой версии анимации удаления.

## Исправление мгновенного удаления

При отключённой анимации сообщение скрывалось, но обработчик завершения мог не вызываться. Теперь мгновенное удаление явно завершает очистку строки. Повторный вызов защищён от дублирования. Это работает и при включении уменьшения анимации во время исчезновения сообщения.

Скачайте обновлённый установщик заново, заменив предыдущий файл в «Загрузках». Повторная установка изменит только компонент удаления, его тесты и эту инструкцию.

## Поведение

- После подтверждения и успешного удаления на сервере пузырь сообщения растворяется за 280 мс и плавно освобождает место в переписке. Надпись «Сообщение удалено» и пустая строка не остаются.
- Обновления чата с удалением другим участником обрабатываются так же. Уже удалённые сообщения при открытии чата не показываются.
- При отмене подтверждения или отказе сервера сообщение остаётся. Участник по-прежнему может удалить только своё, модератор — сообщения в пределах своих прав.
- Удаление закреплённого сообщения убирает закреп. После удаления последнего сообщения появляется обычное пустое состояние чата.
- Сохраняется переход к более ранней истории, в том числе если целый загруженный участок состоит из удалённых сообщений.
- При включённом системном уменьшении анимации пузырь скрывается сразу.

## Установка

Скачайте `update_moy_prihod_message_removal.py` в «Загрузки», остановите приложение и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_moy_prihod_message_removal.py
flutter analyze
flutter test
```

Установщик создаёт резервную копию и допускает повторный запуск. Неизвестные правки в изменяемых файлах приводят к остановке до записи. Конфигурация, зависимости и исправление входа сохраняются.

**Повторно запускать SQL не нужно.** Используется существующее серверное удаление: исходный текст стирается, остаются служебная метка и идентификатор для истории и проверки прав. В интерфейсе удалённой строки больше нет.

После успешных проверок:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Проверьте удаление своего сообщения, отмену удаления и удаление закрепа. Вторая открытая сессия должна убрать удалённое сообщение после получения обновления чата.

## Проверка в среде подготовки

Проверены синтаксис и формат изменённых Dart-файлов и установщик с резервными копиями и повторным запуском. Добавлены тесты исчезновения/схлопывания, отсутствия пустого места и заглушки, уменьшения анимации, удаления из другой сессии, отказа сервера и перехода через удалённую историю.

Flutter SDK в среде подготовки отсутствует: widget-тесты и визуальный результат необходимо проверить на Mac. В первой версии анимации на Mac прошли 106 тестов и упала проверка мгновенного удаления. Эта проверка сохранена; добавлена проверка смены настройки анимации во время удаления и однократного завершения.

Для анимации используются стандартные [SizeTransition](https://api.flutter.dev/flutter/widgets/SizeTransition-class.html) и FadeTransition. Системное уменьшение анимации учитывается через [MediaQuery.disableAnimationsOf](https://api.flutter.dev/flutter/widgets/MediaQuery/disableAnimationsOf.html).

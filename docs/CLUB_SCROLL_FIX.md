# Mellon — возврат к началу экрана клуба

В видео прокручивается экран молодёжного клуба. Раньше список чатов находился в отдельной области фиксированной высоты внутри прокручиваемой страницы. На телефоне жест над списком двигал только его: первые чаты уже были видны, а карточка клуба оставалась за верхней границей экрана.

Теперь при ширине содержимого менее 680 px карточка клуба, ближайшее событие, вкладки и все строки чатов прокручиваются вместе. Проведите пальцем вниз по списку, чтобы вернуться к карточке клуба. Список больше не перехватывает вертикальную прокрутку отдельно от страницы.

Переписка по-прежнему открывается внутри текущего экрана с плавным переходом. При возврате восстанавливается прежняя позиция списка. На широком экране сохраняется отдельная прокрутка списка чатов и переписки. Состав нижней навигации, права, данные и работа уведомлений не изменены.

## Исправление режима без анимаций

В присланном результате анализатор не нашёл замечаний, 202 теста прошли, один упал при открытии и закрытии чата с отключёнными анимациями. Причина — `AnimatedSize` с нулевой длительностью: его callback пытался повторно запустить разметку во время текущего расчёта размеров.

Теперь в этом режиме форма переписки и список переключаются непосредственно, без `AnimatedSize` и `AnimatedSwitcher`. После разметки списка восстанавливается сохранённая позиция прокрутки. Если список стал короче, позиция ограничивается его новой длиной. При включённых анимациях сохраняется прежний плавный переход. Существующие тесты, включая упавший тест, оставлены без изменений.

Если предыдущее исправление прокрутки уже установлено, скачайте `fix_mellon_club_scroll_motion.py` в «Загрузки» и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_club_scroll_motion.py
flutter analyze
flutter test test/club_scroll_test.dart --reporter expanded
flutter test
```

Это исправление меняет только экран клуба и данную инструкцию. Установщик создаёт резервную копию. SQL выполнять не нужно.

## Установка

Скачайте `fix_mellon_club_scroll.py` в «Загрузки». Если запущен `flutter run`, остановите его клавишей `q`. Выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_club_scroll.py
flutter analyze
flutter test test/club_scroll_test.dart test/club_dashboard_test.dart test/club_live_test.dart --reporter expanded
```

Установщик создаёт резервную копию и отказывается перезаписывать неизвестные изменения экрана клуба. Изменяются экран клуба, добавленные проверки и эта инструкция. SQL выполнять не нужно.

В среде подготовки проверены синтаксис Dart, локальные импорты, сохранность остальных файлов и установка с резервным копированием. Flutter SDK отсутствует: анализатор, widget-тесты и проверка на телефоне здесь не запускались.

Добавлены проверки прокрутки до нижних чатов и обратно до карточки клуба с настройками iOS и Android, увеличенного текста, фонового обновления данных, возврата из переписки и независимой прокрутки на широком экране.

## Обновление Netlify

После успешных проверок пересоберите приложение. Для вашей текущей тестовой публикации укажите HTTPS-адрес возврата явно:

```bash
flutter build web --release --dart-define-from-file=config/development.json --dart-define=AUTH_REDIRECT_URL=https://eloquent-entremet-040562.netlify.app/
open -R build/web
```

Перетащите папку `build/web` в раздел Deploys существующего проекта Netlify и дождитесь Published. Ссылка остаётся прежней. Открытую страницу на телефоне обновите после публикации. Файл `development.json` по-прежнему используется для локального запуска; адрес localhost без HTTPS-переопределения не подходит для релизной сборки.

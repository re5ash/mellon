# Обновление «Личный профиль»

Для проекта, в котором уже установлены управление приходом и исправление кнопок, а `flutter test` завершался с 25 успешными тестами. Обновление устанавливается поверх существующих файлов. Настройки подключения, Android runner, зависимости и предыдущие 7 миграций не меняются.

## Что добавлено

- Отображаемое имя — отдельно от личного имени и фамилии.
- Имя, фамилия и дата рождения: необязательные поля, которые можно очистить.
- Календарь на русском языке и хранение даты без часового пояса.
- Переключатель видимости профиля для активных участников своего прихода. У новых аккаунтов видимость отключена; существующий выбор сохраняется.
- Сохранение с блокировкой повторного нажатия, понятной ошибкой и сохранением ввода при сбое.
- Защита от перезаписи изменений из другого окна. «Загрузить сохранённое» запрашивает подтверждение перед заменой несохранённого ввода.
- Прокручиваемая форма с максимальной, а не фиксированной шириной; общие light/dark/system темы.

## Установка на вашем Mac

1. Скачайте новый файл `update_moy_prihod_profile.py`.
2. Откройте **терминал VS Code** в проекте `moy_prihod`. Если в нём работает Flutter, нажмите `q` и дождитесь строки `moy_prihod %`. Если такая строка уже есть, ничего останавливать не нужно.
3. В этом терминале напечатайте `python3` и пробел, затем перетащите скачанный файл из Finder → «Загрузки» в терминал и нажмите Enter. Текущая папка должна оставаться проектом. Если файл лежит в «Загрузках» без суффикса `(1)`, команда будет выглядеть так:

```bash
python3 '/Users/president/Downloads/update_moy_prihod_profile.py'
```

Установщик сначала сверяет все изменяемые файлы и предыдущие миграции. При неизвестных изменениях он ничего не записывает; пришлите его вывод. Резервная копия создаётся рядом с проектом в `moy_prihod_update_backups`. Ваш локальный отчёт `docs/VERIFICATION.md` не перезаписывается.

4. **В том же терминале VS Code** последовательно выполните:

```bash
flutter analyze
flutter test
```

Ожидается 37 тестов: 25 прежних и 12 новых. Этот новый набор ещё нужно запустить на Mac; в среде подготовки Flutter SDK отсутствует. Если есть ошибка, пришлите полный вывод.

5. После успешных проверок **в том же терминале**:

```bash
npx supabase db push
```

В списке новой миграцией должна быть только `202609100008_profile.sql`. Подтвердите её применение. Если предложены неожиданные миграции, сначала пришлите список. Если миграция 8 уже применена и CLI сообщает, что база актуальна, повторно выполнять SQL не нужно. Не запускайте `db reset` и не меняйте старые миграции.

6. **В том же терминале VS Code** запустите приложение:

```bash
flutter run -d chrome --web-port=8080 --dart-define-from-file=config/development.json
```

7. **В приложении в Chrome** откройте «Ещё → Профиль и оформление». Заполните поля, нажмите «Сохранить профиль». После сообщения об успешном сохранении обновите страницу Chrome: сохранённые значения должны загрузиться снова.

## Кто видит данные

| Данные | Доступ через приложение |
|---|---|
| Имя, фамилия, дата рождения | Только владелец профиля через собственный RPC |
| Отображаемое имя при включённой видимости | Владелец и активные участники его прихода |
| Профиль при выключенной видимости | Владелец; обычный просмотр другими участниками закрыт |
| Отображаемое имя заявителя | Также администратор, уполномоченный рассматривать заявку |
| Email и пароль | Существующая система Supabase Auth; не копируются в таблицу профилей |

Приватность профиля не удаляет ранее отправленные сообщения и публикации. Роль супер-администратора приложения не даёт RPC для чтения чужой даты рождения или личных имён. Владелец базы с административным доступом может читать данные в БД — это не сквозное шифрование.

## Проверки и их границы

Выполнены **102 SQL-проверки** PostgreSQL/PGlite: 63 базовые, 19 административных и 20 профиля. Проверены запреты для гостя/чужого аккаунта/администратора, видимость между приходами, отзыв права, версия старых клиентов, очистка даты, повтор запроса, конфликт версий и откат обеих строк при ошибке второй записи. Отчёты — `rls-test-results.txt`, `administration-test-results.txt`, `profile-test-results.txt`.

Проверены синтаксис Dart, локальные импорты, форматирование и установщик. В `test/profile_test.dart` добавлены проверки гостевого режима, сохранения, ошибок и повторов, конфликта, даты, смены аккаунта, обновления токена и прокрутки на трёх размерах экрана при большой системной гарнитуре и клавиатуре. Они **не запускались в среде подготовки**. Проверки на реальном Safari/iPhone и Supabase Auth/PostgREST с разными сессиями также остаются отдельным этапом.

Это обновление не меняет процесс регистрации и не устраняет лимит отправки почты. Следующий этап — восстановление пароля и настройка почтовой доставки.

Технические основания: ограничения доступа к RPC и фиксированный `search_path` описаны в [документации Supabase](https://supabase.com/docs/guides/database/functions); календарь использует штатный [Flutter showDatePicker](https://api.flutter.dev/flutter/material/showDatePicker.html).

# Mellon — кэш чатов в памяти

Обновление устанавливается поверх предыдущих исправлений мгновенного переключения и удаления кружка загрузки.

## Что изменилось

После первого открытия данные чата, последние сообщения и подтверждённые права временно сохраняются в оперативной памяти устройства. При возвращении переписка отображается сразу. Название, описание и состояние архива перепроверяются в фоне. Подписка на новые сообщения и проверка прав продолжают работать, пока чат находится в кэше. Фоновые обновления сами по себе не отмечают сообщения прочитанными.

Кэш удерживает до восьми последних чатов, до 50 последних сообщений в каждом. При превышении лимита освобождается давно не открывавшийся неактивный чат. Через пять минут после ухода из переписки её кэш освобождается; возвращение раньше этого срока сбрасывает отсчёт. Текущая открытая переписка продолжает работать после освобождения места для других чатов.

При выходе из аккаунта или смене пользователя кэш очищается. Изменение членства и ответ сервера об отсутствии доступа также сбрасывают данные соответствующей комнаты. Проверка прав выполняется раз в 20 секунд; очистка после отзыва доступа происходит, когда приложение получает обновлённый ответ сервера. Неудачные загрузки не сохраняются как успешный кэш. Чат с правом только чтения может оставаться в кэше, отправка в нём не разрешается.

Переписка не записывается этим кэшем в файлы устройства. После закрытия приложения или перезагрузки страницы память освобождается; история на сервере сохраняется и загружается при следующем открытии. Изменений базы данных и новых зависимостей нет.

## Установка на Mac

Сохраните update_mellon_chat_cache.py в Downloads и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_mellon_chat_cache.py && flutter analyze && flutter test
```

Установщик проверяет все изменяемые файлы до записи, создаёт резервную копию рядом с проектом и останавливается при неизвестных локальных изменениях. Повторный запуск ничего не перезаписывает.

Перезапустите локальную версию:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Для опубликованной веб-версии понадобится обычная повторная сборка и обновление папки build/web в существующем проекте Netlify. Сам установщик меняет локальный проект.

## Как проверить

Откройте чат A, затем B и вернитесь в A: уже полученные сообщения должны быть видны сразу. Попросите другого участника написать в A, пока у вас открыт B, затем вернитесь — новые сообщения должны появиться. После выхода из аккаунта войдите другим пользователем и проверьте его собственный доступ к чатам.

Первое открытие комнаты и получение ещё не загруженных сообщений по-прежнему зависят от сети. Кэш ускоряет возвращение к недавно открытым перепискам.

Техническая основа: сохраняются существующие состояния Riverpod с ограниченными по количеству и времени подписками; после освобождения подписок работают штатное autoDispose и отмена фоновых проверок. Документация: https://riverpod.dev/docs/concepts2/auto_dispose.

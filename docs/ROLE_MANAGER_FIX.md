# Исправление открытия управления ролями

Обновление для версии с новым окном «Управление ролями». В присланном журнале `flutter analyze` завершился без замечаний, а `flutter test` показал 131 успешную и 13 неуспешных проверок.

Окно ролей теперь дожидается загрузки аккаунта и его прав перед запросом участников. Раньше оно могло запомнить пустой аккаунт и не показать людей. При смене аккаунта во время загрузки данные предыдущего пользователя не открываются.

Тесты маршрутов используют изолированный источник прав и освобождают контейнер Riverpod до проверки оставшихся таймеров. Существующие проверки маршрутов сохранены. Добавлены проверки задержанной загрузки аккаунта и смены аккаунта во время ожидания прав.

## Установка

Скачайте `fix_mellon_role_manager.py` в «Загрузки». Остановите запущенное приложение клавишей `q` в его терминале и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_role_manager.py
flutter analyze
flutter test
```

Установщик проверит версии файлов и создаст резервную копию изменяемых файлов в соседней папке `moy_prihod_update_backups`. Повторный запуск безопасен. При неизвестных локальных изменениях он остановится до записи файлов.

Это исправление не меняет базу данных. Если `mellon_role_manager.sql` из предыдущего обновления уже выполнен, повторять его не нужно. Если ещё не выполнен, он по-прежнему нужен для работы нового управления ролями.

## Проверка в приложении

После успешных проверок запустите приложение:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Откройте «Управление» → «Роли»: должен появиться список людей и поиск. Выберите человека, измените роль в одном клубе, переключитесь на другой и убедитесь, что его настройки сохранены. Нажмите «Сохранить изменения» и откройте человека повторно.

## Проверка пакета

При подготовке проверены синтаксис Dart, установка на предыдущую версию, повторный запуск, сохранность локальной конфигурации, резервное копирование, отказ при конфликте и откат при ошибке записи. Файлы SQL, формы входа и восстановления пароля сохранены без изменений.

Flutter SDK в среде подготовки отсутствует, поэтому `flutter analyze`, `flutter test` и проверку интерфейса в Chrome необходимо выполнить на вашем Mac. Проверка синтаксиса не заменяет эти команды.

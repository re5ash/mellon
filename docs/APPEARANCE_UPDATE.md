# Оформление «Mellon»

## Что добавлено

Откройте настройки профиля → «Оформление».

- Большая карточка с живым превью чата. Превью и настоящие сообщения используют один компонент.
- Горизонтальные миниатюры: классическая, дневная, ночная и системная темы. Выбор обозначен рамкой.
- Восемь акцентных цветов. Выбранный отмечен кольцом и галочкой. Акцент используется в кнопках, ссылках, переключателях, навигации и исходящих сообщениях.
- Переключатель тёмного оформления и переключатель между пузырями сообщений и плоскими строками.
- Шесть вариантов фона чатов: цвет темы, без узора, небо, оливковые ветви, тёплый свет и лаванда. Встроенные фоны работают без загрузки файлов.
- Отдельный выбор цвета имён. Это локальное оформление: оно не изменяет профиль и то, как имя видят другие пользователи.
- Ступенчатый размер текста: 85%, 92.5%, 100%, 107.5%, 115%, 122.5%, 130%. Он действует во всём приложении и учитывает системное увеличение текста.
- Ночная смена по местному времени устройства с настройкой начала/окончания и палитры («Синяя ночь», «Графит»). По умолчанию расписание отключено, предложенное время — 22:00–07:00.

Все настройки применяются сразу. Кнопки «Сохранить» нет. Состояние хранится одним JSON-значением `appearance_v1` в SharedPreferencesAsync; старый `theme_mode` читается при первом переходе. Записи выполняются последовательно, чтобы более раннее изменение не перезаписало новое. Ошибка записи показывается в разделе оформления с кнопкой повтора. Настройки относятся к устройству/браузеру и не синхронизируются между устройствами.

В режиме «Системная» светлая и тёмная темы следуют настройкам устройства. Если включено расписание, ночью оно включает ночную палитру, а по окончании возвращает выбранную дневную/системную тему. Ручной выбор любой темы или переключение тёмного оформления отключает расписание. Интервал может пересекать полночь. Начало и окончание не могут совпадать. Пока приложение открыто, проверка выполняется на границах минут; после возврата в него — сразу.

Категории «Расписание», «События», «Помощь» сохраняют свои смысловые цвета иконок. Выделение активного раздела, кнопки и ссылки используют выбранный акцент.

## Установка

Остановите запущенный Flutter клавишей `q`. Скачайте `update_moy_prihod_appearance.py` в «Загрузки» и выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/update_moy_prihod_appearance.py
flutter analyze
flutter test
```

Установщик рассчитан на последнюю версию с 85 проходящими тестами и исправлением ввода пароля. До записи проверяются контрольные суммы; при конфликте изменение не выполняется. Создаётся резервная копия изменённых файлов. При ошибке записи выполняется откат. Повторный запуск не меняет уже обновлённые файлы.

После успешных проверок:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

Новые зависимости и SQL-миграции не нужны. Конфигурация Supabase, доступы, пароли, данные чатов и ранее исправленная форма входа не изменяются.

## Проверка

Добавлены 11 тестов в `test/appearance_test.dart`: чтение и миграция настроек; испорченные значения; границы ночного интервала; последовательная запись при быстрых изменениях; ошибка записи и повтор; приоритет ручного выбора; применение цвета и размера текста на другой странице; системная яркость; оформление реальных входящих/исходящих сообщений; ночное переключение и возврат приложения; узкий/широкий экран с увеличенным текстом. В существующем тесте профиля проверяется новый вход в раздел оформления вместо прежних трёх чипов.

При подготовке разобран синтаксис изменённых Dart-файлов, проверены импорты, API и совместимость установщика. **Flutter analyze, Flutter test и визуальная проверка работающего Flutter-интерфейса в этой среде не запускались: SDK отсутствует.**

После запуска на Mac:

1. Откройте «Оформление», смените тему и акцент. Перейдите в приход и чат: оформление должно примениться там тоже.
2. Переключите вид сообщений, обои и цвет имён. Проверьте превью и настоящий чат.
3. Передвиньте размер текста. Откройте другую страницу, затем вернитесь.
4. Перезапустите приложение с тем же адресом/портом браузера: выбранные значения должны восстановиться.
5. Включите ночное расписание с ближайшим временем начала; убедитесь, что тема переключается и возвращается после окончания. Проверьте возврат в приложение после паузы.
6. Выберите тему вручную и убедитесь, что расписание отключилось.

Опорные API: [SharedPreferencesAsync](https://pub.dev/packages/shared_preferences), [TextScaler](https://api.flutter.dev/flutter/painting/TextScaler-class.html), [AppLifecycleListener](https://api.flutter.dev/flutter/widgets/AppLifecycleListener-class.html).

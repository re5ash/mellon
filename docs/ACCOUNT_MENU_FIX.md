# Mellon — нажатия в профильном меню

Исправлена блокировка пунктов «Настройки», «Управление» и «Выйти» после перехода из меню. Раньше флаг занятого меню оставался включённым до закрытия открытой страницы: `push` возвращает результат при возврате назад. Теперь навигация не удерживает этот флаг. Возможность вернуться назад сохраняется.

Во время входа и выхода из аккаунта меню временно недоступно для повторных нажатий. При ошибке показывается сообщение, после чего действие можно повторить. Изменения ролей, базы данных и дизайна не требуются.

## Установка

Скачайте `fix_mellon_account_menu.py` в «Загрузки». В терминале выполните:

```bash
cd ~/Desktop/moy_prihod
python3 ~/Downloads/fix_mellon_account_menu.py
flutter analyze
flutter test test/account_menu_test.dart --reporter expanded
```

Установщик проверяет исходные файлы перед записью и сохраняет резервную копию в соседнюю папку `moy_prihod_update_backups`. Неизвестные изменения в затрагиваемом файле останавливают установку. Повторный запуск безопасен.

После прохождения целевой проверки запустите полный набор `flutter test`.

## Проверка в приложении

Войдите под аккаунтом с доступом к управлению. Через верхнее меню последовательно откройте «Настройки», «Управление», снова «Настройки», затем выберите «Выйти». Между нажатиями не нужно возвращаться на главный экран. После выхода должна открыться лента, а в меню появиться «Войти». Снова войдите и повторите переходы.

Для локального запуска:

```bash
flutter run -d chrome --profile --web-port=8080 --dart-define-from-file=config/development.json
```

## Обновление ссылки для друга

Установка исправления на Mac не обновляет опубликованную версию автоматически. После успешных проверок соберите веб-версию с тем же файлом конфигурации, который использовали при последней публикации. Скрипт проекта `scripts/build_web.sh` принимает путь к этому файлу; по умолчанию использует `config/production.json`.

В Netlify откройте существующий проект и раздел Deploys. Загрузите заново собранную папку `build/web`. Ссылка приложения останется прежней. После публикации обновите страницу приложения на устройствах обоих тестировщиков.

## Что проверено при подготовке

Добавлены два виджет-теста: последовательная навигация в том же меню с возвратом и выходом; защита от повторного выхода и возможность повторить его после ошибки. Тесты используют подставную сессию без сетевого клиента Supabase.

Установщик, границы изменений и синтаксис Dart проверяются в среде подготовки. Flutter SDK в ней отсутствует: прохождение `flutter analyze` и виджет-тестов необходимо подтвердить на Mac командами выше.
